# 2026.310.2146 — feat(design): the os owns every conversion, as section 16.4 says (batch 53)

## Summary

Implements the **operator ruling recorded on #838**: where section 16.4 says the os of the stack's source owns
every conversion, the schema must carry fields for it. This is that amendment -- `kind:distro` was ruled a **gap**,
not a narrowing.

`#Os` gains **ten fields**, each with a named struct (S1):

| field | what it is |
|---|---|
| `inherit` / `inherit_package` | the `os` words this one extends, and the packages every build gets |
| `bootstrap` (`#OsBootstrap`) | how the root filesystem is made: the `install` command, the `package` it installs, the `cache_mount` kept between runs |
| `workaround` | a known defect of this os, and what the build does about it |
| `format` (`#OsFormat`, keyed by package manager) | the `validate` rules a rendered unit must pass, and the `local_package` only this os supplies |
| `base_user` | the account an image adopts rather than creates |
| `bootstrapper` (`#OsBootstrapper`) | the from-scratch tool: `pacstrap`, `debootstrap` or `alpine` |
| `bootloader` | the bootloader an installer writes |
| `disk_layout` (`#OsDiskLayout`) | the partitions an installer creates |
| `installer` (`#OsInstaller`) | the answer file an unattended install reads, and the volume it is served on |

The section 16.4 field table grows with them, and the Fedora `os:` example **exercises all ten**.

| file | what changed |
|---|---|
| `DESIGN.cue` | `#Os` plus `#OsBootstrap`, `#OsFormat`, `#OsBootstrapper`, `#OsDiskLayout`, `#OsInstaller` |
| `DESIGN.md` | the section 16.4 field table, and the Fedora example |
| `design/dulling.tsv` | `kind:distro` becomes sharp |
| `design/dulling-disposition.md` | regenerated; the header now reads 180 sharp, 81 dulled (57 settled, 24 owed) |
