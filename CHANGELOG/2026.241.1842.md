## Summary

Brings the project pi config (`.pi/`) fully in sync with the current Claude Code config (`.claude/settings.json`) and adds the requested packages.

**Packages (`.pi/settings.json`):**
- **Added:** `npm:pi-web-access@0.27.0` (web search/content extraction), `npm:pi-fabric@0.70.0` (tool/agent runtime), `npm:pi-claude-marketplace@0.18.0` (Claude-plugin-marketplace bridge), `git:github.com/Michaelliv/pi-goal@v0.1.7` (persistent goals)
- **Upgraded:** `npm:pi-mcp-adapter` 2.26.1 → 2.31.0
- **Removed:** `git:github.com/opencharly/marketplace` — its charly-* skills are now installed by the pi-claude-marketplace import; the Claude config is the single source of truth for the plugin topology. `umbrella_load_skills` reads the `marketplace/` submodule directly, so R0 skill loading is unaffected.

**Housekeeping:** `.gitignore` covers the regenerable state (`.pi/pi-claude-marketplace/` — 50MB of marketplace clones, `.pi/agents/`, `.pi/fabric/`, `.pi/claude-plugins.local.json`); `.pi/README.md` documents the packages and the sync flow.
