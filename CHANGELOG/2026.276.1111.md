# 2026.276.1111 — feat(harness): wire the DeepWiki MCP server into every MCP-capable surface, with the gate that keeps them wired

Wires the public **DeepWiki** MCP server (`https://mcp.deepwiki.com/mcp`) into every MCP-capable harness surface the umbrella owns, and adds the gate that keeps them wired.

Rule 8 puts every harness's configuration at this root and **only** here, so this is an umbrella-only change: no submodule, no gitlink, no pin.

## Summary

An agent that cannot answer *"how is this repo put together?"* from a grep guesses. DeepWiki answers it from a GitHub repo's indexed documentation, so the umbrella's harnesses get the tool — and, because a config surface that silently stops being read is worse than none, a gate that fails when it goes missing.

**Files (6, +86/−3):**

- **`.mcp.json`** (new) — Claude Code's project-scoped MCP file, a remote HTTP server (`"type": "http"` + `"url"`). The same file is auto-loaded by **pi** (via `pi-mcp-adapter`) and by **Reasonix**, which both read Claude Code's `.mcp.json` — so ONE file wires three harnesses.
- **`.claude/settings.json`** — `"enabledMcpjsonServers": ["deepwiki"]`, so the server is pre-approved instead of prompting on every session.
- **`opencode.json`** — top-level `mcp` map entry (`"type": "remote"` + `"url"`).
- **`.codex/config.toml`** — `[mcp_servers.deepwiki]` with `url` (Codex's streamable-HTTP form). The `network_access = false` above it gates Codex's own **Bash sandbox**, not its MCP client.
- **`scripts/check-harness-config.mjs`** — new **check 6**: a `[surface, extractor, who]` table asserting every MCP surface declares the DeepWiki server, plus a minimal dependency-free TOML section reader so the Codex surface is guarded without pulling in a TOML library. Each surface's syntax was verified against that harness's own binary/docs — no syntax was guessed.
- **`AGENTS.md`** — the one-line agent guidance (query `deepwiki` where a grep cannot answer *how*; **the code in the repos stays the authority**) and the gate-script mention in Hooks doctrine.
