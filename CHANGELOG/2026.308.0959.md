# 2026.308.0959 — feat(design): carry a unit's write half as the fields it is (batch 14)

## Summary

Batch 14 of the DESIGN amendments the capability ledger records (tracked in #838). `verb:unit` probes
**and writes** a unit today: `content`/`drop_in_for` render it, `enable` turns it on. The ledger called
the write half lost, because a verb observes and never changes state.

**It is not lost — it is a field**, which is exactly what D-VERB-1 says a state change is:

- a `file:` entry writes the unit (or its drop-in, at its own path);
- a `service` declaration enables it;
- the probe half is the `service` check on `name`/`present`/`enabled` the design already has.

So the row becomes `sharp` against the fields it names, with **D-VERB-1 and §14.4 cited** rather than
only the requirement that forbids the verb.
