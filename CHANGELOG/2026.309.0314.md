# 2026.309.0314 — feat(design): let a hook be an auxiliary script (batch 28)

## Summary

Batch 28 of the DESIGN amendments the capability ledger records (tracked in #838). A `hook:` node emitted a
script **and wired it into the harness's settings**. Today a hook can also emit a script **without wiring
it** -- one a command runs by path -- and that form had no field.

`#Hook` gains `wire` (default `true`); `wire: false` is the auxiliary script. **`kind:hook` becomes sharp.**

| file | what changed |
|---|---|
| `DESIGN.cue` | `#Hook` gains `wire: *true or bool` |
| `DESIGN.md` | the shared project gains an auxiliary hook beside the wired one |
| `design/dulling.tsv` | `kind:hook` becomes sharp |
| `design/dulling-disposition.md` | regenerated |

The default does the work here: a hook that says nothing is **wired**, exactly as before, so no existing
document changes meaning. The unwired form is opt-in and named.
