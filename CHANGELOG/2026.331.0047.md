# 2026.331.0047 — chore(harness)!: retire the reasonix harness binding

## Summary

Retire the **reasonix** harness binding from the umbrella in one hard cutover. reasonix is a third-party agent-harness CLI (like Claude Code / Codex / pi / DSH); this repo carried a first-class integration for it, not a charly candy, box, pod, layer, deploy, VM, check bed or CUE shape.

Removed:

- `reasonix.toml`, the tracked `.reasonix/` directory (9 files: hooks, `settings.json`, the Python web-search sidecar and its test, the watch list) and `design/REASONIX.md`;
- the reasonix arms and their self-test mutations from `scripts/check-harness-config.mjs` (checks 7/7b/8/9/10/11), `scripts/sync-skill-bindings.mjs` (+ selftest), `scripts/lib/corpus.mjs` and `scripts/init-submodules.sh`;
- every live prose reference in `README.md`, `charly.yml`, `.pi/`, `.dsh/`, `.agents/` and the gate scripts.

Historical `CHANGELOG/` mentions are retained: R5 permits history and the operator chose not to rewrite it. The org sweep is producer-first: the `opencharly/charly` leg merged at `v2026.330.2137`; the seven generated projections in `opencharly/marketplace` regenerate after this PR's own tag, and this repo's marketplace gitlink advances last.
