# 2026.309.0158 — feat(design): close the writer list over the writers that exist (batch 26)

## Summary

Batch 26 of the DESIGN amendments the capability ledger records (tracked in #838). **D-CLI-2 is a *closed*
list** — only the commands on it may write an authored file — and it named **eight** while the binary has
**sixteen** that do. A closed list that omits real writers is worse than no list: it reads as a guarantee
and is a gap.

The list now carries the eight real writers it was missing:

`candy set`, `candy add-<fmt>`, `candy params`, `config setup`, `udev install`, `vm clone`, `vm import`,
`vm import-container-disk`

| file | what changed |
|---|---|
| `DESIGN.md` | D-CLI-2 lists all sixteen writers |
| `design/dulling.tsv` | `command:candy`, `command:config`, `command:udev` become sharp |
| `design/dulling-disposition.md` | regenerated |

**Two rows stay dulled, deliberately and for different reasons:**

- `vm bake|build|…` — its `retag` and `seed` operations are **not** authored-file writers and still have
  no listed home;
- `udev generate|install|remove` — that is a question about typed **operations**, not about the writer
  list, and adding a command to a list does not answer it.
