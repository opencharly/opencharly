# 2026.309.1852 — feat(design): let a file check assert a file's size (batch 45)

## Summary

Batch 45 of the DESIGN amendments (tracked in #838). The media gate's job is to prove a run's captured
evidence is **real** — not an empty file, not a truncated recording. The design could assert a file's
content, mode, owner and digest, but **never its size**, so the per-file minimum byte floors had nowhere to
go.

`#FileCheck` gains **`size`**, a matcher. One captured artefact is one `file:` check (`path` plus a `size`
floor), and the `transcode:` verb assembles the capture — so **`verb:media` becomes sharp**.

|---|---|
| `DESIGN.cue` | `#FileCheck` gains `size?: #Matcher` |
| `DESIGN.md` | a size floor beside the existing file checks |
| `design/dulling.tsv` | `verb:media` becomes sharp |
| `design/dulling-disposition.md` | regenerated |
