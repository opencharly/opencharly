# 2026.327.1854 — feat(design)!: six problem-first grievances on a word-blind core and one IR, and D-VAL-16 checks that every example declares its plugins

## Summary

GRIEVANCES.md is rewritten around the two ideas every OpenCharly answer rests on:

- **the core knows no words:** every word an author writes is served by a plugin the project declares;
- **everything compiles to one IR:** the ordered install actions that `build` and `realize` read.

DESIGN.md gains a rule and a design-check control that hold every example to the first idea.

**GRIEVANCES.md** (closes opencharly/opencharly#1249)
- Six grievances instead of five. The new first one, *"Every tool has a fixed vocabulary, and every target needs its own translator."*, defines a word, the core, a plugin, the `plugin:` directive, a candy and the IR. It includes the seven-action table in plain English, a worked IR, and the N×M → N+M argument.
- The other five are reordered and retitled. Every title is one sentence that states the problem only, with no OpenCharly word in it.
- From §2 on, the examples build **one growing project**. Each block is the complete document so far, and the lines a section adds carry `# new in §N` and are explained there. Every candy comes from `opencharly/layer-example` at `v2026.327.1754`, which opencharly/layer-example#3 added (the producer leg, merged). The three candy blocks are shown as that repository ships them.
- Every example declares the **real** plugin repositories its words need, at their newest releases, with digests computed the way PR #1248 did (the sha256 of `git archive --format=tar <release>`, twice, stable):
  - `opencharly/plugin-candy-kind`: the candy body
  - `opencharly/plugin-build`: building a box
  - `opencharly/plugin-substrate`: the `pod` and `vm` kinds
  - `opencharly/plugin-deploy-pod` and `opencharly/plugin-deploy-vm`: realizing them
  - `opencharly/plugin-file` and `opencharly/plugin-http`: the two check verbs

  The method reproduces the existing `distro-cachyos` digest exactly.
- Drift from DESIGN is corrected:
  - "install plan" is now **IR**.
  - `supervisord`/`systemd` appear only as values of the `os` node's init row, which renders the `service` action.
  - Device paths become capability words (`device: {kvm, vhost_net}`, `device: {fuse, tun}`, `isolation: {userns}`), with the paths named once in parentheses.
  - A check's phase follows from its verb.
  - Labels carry checks only.
- The document stands alone: every term is defined in plain language where it first appears.

**DESIGN.md, `rules.cue`, a negative case** (closes opencharly/opencharly#1250, a DESIGN amendment)
- New §12.4 row **D-VAL-16**: *every kind and verb word a document writes is served by a plugin its `plugin:` declares, or by a plugin candy of the same document (D-PLUG-4)*, with the design check `rules.cue`.
- `design/example/rules.cue` carries the check and **one owner table**, one row per word:
  - `target` is the §3.1 owner, under the repository §7 names.
  - `current` is every repository that serves the word today, measured from each repository's `plugin.providers` manifest on 2026-11-23. Today a kind and the deploy target that realizes it are two repositories.
  - A document passes by declaring the target, or every current repository. The operator chose this shape in session, so that DESIGN keeps its target names while GRIEVANCES names the real repositories.
  - The `current` column shrinks as opencharly/opencharly#1251 consolidates the repositories.
  - A word with no row (its target repository is not named in §7: the desktop, agent and documentation words) is not checked, and the table's comment says so.
- A plugin candy's own words count as declared: a plugin's repository uses its words without declaring itself.
- The nine standalone DESIGN examples that write first-party words now declare their plugins (flow style, the §7 pins, as `complete-project` already did). Each declares only what it uses, so D-PLUG-6 (no unused plugin) holds.
- `design/negative/plug-undeclared.yaml` is a `pod:` without its plugin. It passes the schema and fails only D-VAL-16.

**README.md, AGENTS.md:** the "five grievances" references and titles now read six, with the new titles.
