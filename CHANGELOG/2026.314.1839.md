### The advance, and why not the wave

`charly task sync` is ORG-WIDE: this tree carries ~380 pins behind from the `.github#192` reconcile sweep, so the wave would carry all of them in a PR whose subject names one repo. This change therefore uses the narrow mechanism the rulebook states for a gitlink that is not a wave — roll the checkout to the ref the remote serves, and `git add` the gitlink — and never hand-edits a gitlink.
