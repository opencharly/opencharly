# 2026.234.2108 — fix: escape backticks in umbrella-gates rules template (pi extension parse error)

## Summary

Fixes the pi extension load failure at the umbrella root:

```
Error: Failed to load extension ".../.pi/extensions/umbrella-gates.ts": ParseError: Missing semicolon.
 ...umbrella-gates.ts:100:7
```

The `buildRulesBlock()` template literal contained an **unescaped backtick pair** around `` `CHANGELOG/<calver>.md` `` (line 100). The first backtick terminated the template literal early, producing invalid syntax. As a result pi's jiti loader rejected the module and the extension never loaded — killing all three of its functions at once: the bash `tool_call` gate interception (pre-commit/pre-push mechanics), the `umbrella_load_skills` tool, and the every-turn system-prompt rules injection.

The fix escapes the pair to `` \`CHANGELOG/<calver>.md\` ``, matching the already-correct pattern on the Assisted-by line (line 102). The same change ships an **in-tree regression gate** (`scripts/check-umbrella-gates-syntax.mjs`, wired into `task verify` and `.github/workflows/verify.yml`) so the repo's own CI fails on a recurrence of this defect.
