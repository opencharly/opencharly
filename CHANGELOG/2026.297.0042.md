# 2026.297.0042 — fix(hooks): pin the lint leg to the module's toolchain, and the alias leg to the diff prefixes

## Summary

The umbrella's commit gate has two legs, and on a host that is not the CI host both
of them decide wrongly. Both are fixed here, in the ONE canonical copy of the hook
(Part II #5: harness config lives only in the umbrella).

**1. The lint leg ran the linter under the HOST's ambient Go.** `golangci-lint`
v2.13.2 links `x/tools` v0.49.0, whose export-data reader understands version 4 and
below; the host's `go1.27.3` emits version 5. The linter then cannot read the
compiler's own export data and reports `typecheck` failures **on a clean tree** —
the gate blocked a commit for code that is fine. The leg now runs the linter under
the toolchain the module's own `go.mod`/`go.work` names, which is the selection CI
makes through `go-version-file`. A named toolchain that cannot be obtained on this
host is an ENVIRONMENT problem, not a code problem: the leg is skipped with a
visible `NOTE` instead of blocking, the same fail-open the timeout and exception
paths already take.

**2. The alias leg recovered each hunk's path from a diff header whose prefixes are a
USER setting.** `git diff --cached` emits `+++ i/<path>` when
`diff.mnemonicPrefix` is set (it is, on this host) and `+++ <path>` when
`diff.noprefix` is set. The gate looked for `+++ b/<path>`, so under either setting
the path was never recovered and the grouped-alias check **silently stopped
blocking** — a guardrail that disables itself under configuration. The prefixes are
now pinned on the diff call, which overrides both settings.

The two failures the repo's own suite reported are the second defect's symptom, and
both are fixed here rather than filed: the suite was RED on this host at `HEAD`,
before this change, and the same suite is GREEN on this tree.

| file | what changed |
|---|---|
| `.claude/hooks/pre-commit-gate.sh` | the lint leg pins the toolchain the module names (and skips with a `NOTE` when it cannot be obtained); the alias leg pins the diff prefixes |
| `.claude/hooks/gate_test.py` | the coverage for both: a stub linter that records the `GOTOOLCHAIN` it was invoked under, a stub `go`, and the grouped-alias case under `diff.noprefix` and `diff.mnemonicPrefix` |
