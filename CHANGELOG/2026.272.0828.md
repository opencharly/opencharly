### The responsibility contract (commit 1)

**The main session owns the OUTCOME; a subagent only EXECUTES ITS BRIEF.**

| Duty | Owner |
|---|---|
| **Opens the PR** | the **author** — the subagent for its brief, the main session for its own work |
| **Watches the verdict / reads every BLOCK in full** | the **main session** |
| **Fixes a BLOCK** | the **PR author** (one editor per change) |
| **Guarantees it is FULLY fixed before the next push** | the **main session** — enumerate every block, confirm each addressed against the author's self-audit *and* its own read of the diff; all findings in **ONE** commit; a partial fix is never pushed |
| **Answers comments on other sessions' blocking PRs** | the **main session** (rule 9 channel; owns `BLOCKS`/`STATUS`/`TAKING OVER`/`HANDING OVER`) |
| **Writes the PR body / decides the merge** | the **main session** (merge only on a validator PASS) |

Plus the **Rule of ambiguity**: *if a duty is not named, it belongs to the main session; a
subagent never assumes a duty it was not given.*

### The subagent lifecycle (commit 2)

- **Instruct** — the brief as a **structural template**: task; deliverable + DoD; **named
  skills** with the *load-with-the-`skill`-tool-before-the-first-tool-call* mandate; the
  **embedded** pre-validator self-audit; context; **head-anchored evidence**; rules; completion.
  *Omitting a field is an R0 violation.*
- **Use** — a fresh session per task; **a rotation is STOP + spawn** (`opencode session delete
  <id>` (deletes children) or `POST /api/session/{id}/interrupt`), then **confirm stopped**. A
  successor spawned while the predecessor lives is a **duplicate-owner violation** — the
  `charly#714` evidence (two sessions on one scope) is cited in the section.
- **Monitor** — **artifact + cadence + loop**, never a counter. A "message" is one **assistant
  turn**; a long task legitimately takes many, so turn count is **not** progress and **not** a
  stall. Progress is a **changed artifact**; steady tool calls = **working**; the pathology is a
  **repeated failing action**. Rotate only on **re-brief thrash (>2)**, **idle-past-window with
  no artifact**, or a **repeated failing action**.
