# 2026.243.0952 — feat(pi): goal completion discipline in the system prompt

## Summary

Add the goal-completion discipline to the pi system prompt (`.pi/APPEND_SYSTEM.md`):

1. **Merged-upstream check is mandatory** — a goal is not complete while any of its PRs is open: after validator PASS, arm the repo's own native auto-merge (`gh pr merge --auto --squash` + `gh pr update-branch` for BEHIND PRs), never self-merge, and list each PR's merged state in the completion audit.
2. **Todo completion is mandatory** — every todo item completed (or explicitly deleted-with-reason) before completion.
3. **Goals are living contracts** — new issues (validator BLOCKs, arming/merge failures, new divergences, follow-up batches) must be folded into the goal objective REGULARLY on discovery; never silently deferred to unnamed follow-ups; only genuinely external/operator-owned dependencies may be parked (with exact repo + required action).

Motivation: this session's first goal closed with validator-green-but-unmerged PRs and an in_progress todo — exactly the failure the user flagged. The rule now codifies the fix.
