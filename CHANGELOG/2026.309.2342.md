# 2026.309.2342 — docs(design): there is no verb per command-line tool (batch 50)

## Summary

Batch 50 of the DESIGN amendments (tracked in #838). `mise:` ran arbitrary mise subcommands with
args/tool/task/config/tools_env/run_as. **The design's answer is in the row's own target and in two definitions I
read rather than guessed:**

```cue
#StepAlt:   {run: {run!: #Text, #RunFields...}, ...}   // a command step
#StepFields:{id?, run_as?: #Name, timeout: ...}         // who the step runs as
```

So a **`builder` row provisions the tool** and a **`run:` step invokes it**; the tool's own manifests are
`file:` steps. **What is retired is the VERB, not the capability** — there is no verb per command-line tool,
and the arbitrary subcommand a tool offers is the run step's command line.

A.9 records the trade; the row takes `accept retirement`.
