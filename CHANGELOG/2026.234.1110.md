# 2026.234.1110 — fix: escape backticks in umbrella-gates.ts template literal

## Summary

Fixes a `ParseError: Missing semicolon` in `.pi/extensions/umbrella-gates.ts` caused by unescaped backticks inside the `buildRulesBlock()` template literal. The backticks around Markdown code spans (`` \`CHANGELOG/<calver>.md\` `` and the `Assisted-by` example) prematurely terminated the template string, making the extension unloadable.

Also adds `.pi/npm/` to `.gitignore` so that pi project-local package installs are ignored at the root level, matching `charly/.gitignore`.

Diff items: `.pi/extensions/umbrella-gates.ts`, `.gitignore`, `CHANGELOG/2026.234.1041.md`.
