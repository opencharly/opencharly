## Summary

Batch 48 of the DESIGN amendments (tracked in #838). A `kindcluster:` template carries three policy blocks the
design lacked. **I did not guess their shapes — I read them in the product's own
`contract/schema/kubernetes.cue`:**

```cue
#KubernetesImagesDefaults:   {pull_policy, pull_secrets}
#KubernetesPodDefaults:      {priority_class, tolerations, node_selector}
#KubernetesResourceDefaults: {labels, annotations}
```

`#KubernetesFields` gains four fields — how the cluster pulls a workload's image, where it schedules it, and
what it adds to every object it applies, each **when the workload names none**:

| field | what it is |
|---|---|
| `image_default` | the pull policy and pull secrets a workload's image gets |
| `pod_default` | the priority and node selector it is scheduled with, plus raw tolerations — a foreign-shape payload that stays open (S10) |
| `label` / `annotation` | what the cluster adds to every object it applies |

`kind:kindcluster` becomes **sharp** — its residue was only the three default blocks.

`kind:kubernetes` **stays `dulled`**: round 1 correctly caught that its capability text also names the
kubeconfig FILE path and the kubevirt platform knobs, and four fields on the policy surface do not make the
whole row sharp. Its dulled-by now names exactly what is covered — nine fields — and exactly what is not.

| file | what changed |
|---|---|
| `DESIGN.cue` | four fields on `#KubernetesFields`, two named structs, and the `_deployField` union extended |
| `DESIGN.md` | the kind-demo cluster example exercises all four |
| `design/dulling.tsv` | `kind:kindcluster` becomes sharp; `kind:kubernetes` stays `dulled`, and its row declares **two** edits: the **design node** is rewritten from "a `kubernetes:` node" to "the cluster policy surface on `#KubernetesFields`", and the **dulled-by** is rewritten to name the nine covered fields and the two gaps. Its `action` is unchanged at `amend D-DEP-1` — an earlier commit of this branch had moved it to `D-KIND-1` with no rationale, which round 4 caught and this head reverts. |
| `design/dulling-disposition.md` | regenerated |
