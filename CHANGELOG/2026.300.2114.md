*Mechanism* — in the first counterfactual the SAME two arms fail in both halves (`a nested path's divergence held the parent back`, `a colon-named path was not read as itself`), and in the second the SAME six arms fail in both halves. The arms that catch a broken definition are the SPECIAL-path arms, whose expectations are the fixture's own shas (`$pinned_sha`); the arms that catch a reader answering with the checkout's STATE are different arms again. Neither family consults this oracle, so routing the oracle through the definition or through the STATE disarms nothing. *Missed control* — nothing in the file or the gate could tell a comment that overstates its case from one that states it, because a comment is prose and the gate reads behaviour. *Blast radius* — the comment's claim, and nothing else. *Root fix* — the shipped wording states what is true and checkable (the sweep above), and drops the clause the measurement does not support. The R1 record is this paragraph; the finding was not filed away, because it is on this PR's own line of work and it is fixed in it.
