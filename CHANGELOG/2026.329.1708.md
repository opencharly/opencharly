# 2026.329.1708 — docs(agents): mandate the full closed watcher event set

## Summary

The rulebook required "a watcher" but mandated only one event class in passing. The watcher's event
set is **CLOSED** — `EVENT_NAMES` in `scripts/gh/lib/watch.ts`: `verdict`, `merged`, `closed`,
`conflict`, `comment`, `stall` — and this makes **all of it mandatory wherever it applies**, as a
table in the rulebook:

| Event | Fires on | Arm it for |
|---|---|---|
| `verdict` | the validator's `PASS`/`BLOCK`/`INCONCLUSIVE` on the head | every PR you own |
| `merged` | the PR merged | every PR you own; a producer leg you depend on |
| `closed` | closed without merging — find its successor | every PR you own; a blocker that may die |
| `conflict` | the PR conflicts with its base, so the validator cannot run | every PR you own |
| `comment` | a new comment on the PR or issue | any thread you must answer, and every item you coordinate on |
| `stall` | no progress for N minutes (open, unmerged) | another session's item that blocks you — the takeover candidate |

Consequences now stated in the rulebook: an **own PR** arms the default
`verdict,merged,closed,conflict`; add `comment` whenever a reply is owed; a **blocking item owned
elsewhere** arms `merged,closed,stall` (plus `comment`); **several items** share ONE watch; a **long
bed or command** is its own managed background job; a **file/log/stream** is the Monitor. **A wait
without its watcher is not a wait**, and the watcher is re-armed after every wake.

Edit sites:
- **AGENTS.md** — the "Agents, Workflows & Teams" table and mandate, the **Continuous operation**
  clause (every event the wait requires), and the **Continuity** checklist item.
- **`.agents/skills/git-workflow/SKILL.md`** — the commands: the union, `--events … ,comment` for an
  owed reply, `merged,closed,stall` for a blocker, a bed as a job, a stream as the Monitor.
- **`.agents/skills/agents/SKILL.md`** — the lifecycle: arm before the wait, the union, one watcher
  per session, re-arming REPLACES, act-and-re-arm.
