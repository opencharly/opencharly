# 2026.234.0000 — Adopt the org-wide validation chain

The umbrella's custom `auto-merge.yml` was broken (no checkout — `gh pr
merge --auto` and the inline tag computation failed with "not a git
repository") and merged on the `verify` gate alone, without the org's fresh
AI validation. It is replaced by the org-wide chain used by every opencharly
repo: the `charly/pr-validator` dispatcher (waits for the `verify` pinning
gate, then runs the org reusable validator via `pi-review-action`, enabling
native auto-merge on PASS) and the `tag-on-merge` sweep (tags every merged
PR with its CalVer snapshot metaver). Repo settings now match charly
(auto-merge allowed, squash-only, delete branch on merge), and branch
protection on `main` requires `verify` + `validate / validate`.
