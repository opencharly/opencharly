# 2026.323.1156 — feat: register layer-cdi in the umbrella

## Summary

Register `layer-cdi` in the umbrella. One submodule, its `.gitmodules` entry, one README org-map row, and the header census.

`layer-cdi` was created **2026-11-17** and holds the CDI pod contract — the build-time assertions that no driver user-space and no `nvidia*` binary is baked into a pod image. It had no umbrella gitlink at all: 400 org repos, 396 declared paths. So the one repo that DEFINES what a pod may contain was the one repo the umbrella could not audit, and that is exactly how its assertion drifted from `layer-cuda`'s actual strip set without anyone noticing.

```console
$ gh repo list opencharly --limit 400 --json name --jq '.[].name' | wc -l
400
$ grep -c 'path = ' .gitmodules
396            # before this PR
```

`pod-cdi` and `vm-nvidia` — the two repos this cutover also created — were already registered by #1141. `layer-cdi` was the gap.
