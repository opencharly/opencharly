## How tested

**Pin verification, pasted — because the previous version of this section pasted a gate that does not compare SHAs, which the validator correctly called out.** For each advanced gitlink, the recorded SHA is compared against the submodule's own upstream:

```
$ for N in action-review dotgithub layer-charly-internals layer-charly-internals-extra marketplace plugin-build \
           plugin-deploy-vm plugin-doctor plugin-fleet plugin-kubevirt plugin-substrate plugin-vm sdk spec; do
    SHA=$(git ls-tree HEAD "$N" | awk '{print $3}')
    printf "%-30s %s  tag=%-22s ahead-of-sha-to-main=%s\n" "$N" "${SHA:0:9}" \
      "$(git -C "$N" tag --points-at "$SHA" | head -1)" "$(git -C "$N" rev-list --count "$SHA"..origin/main)"
```
