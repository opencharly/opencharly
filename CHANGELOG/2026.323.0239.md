## What the entry adds beyond the table

**Three process rules this stretch bought, each with the round that bought it**, because the ledger's job is
to make the next session cheaper and a table of PR numbers does not:

1. **Walk every bullet and table row before the first push and ask, per line: is a pasted command and its
   output adjacent?** A claim and its paste are both well-formed markdown, so no gate in this repo can tell a
   true sentence from a false one.

   were a paste that outlived the commit it described.
