# 2026.295.0932 — docs(containerd): document the seccomp profile, libkrun/crun versions, the readiness hook, and rename the lease images

## Summary

W1 of the containerd / libkrun / k3s programme: four documentation residuals in the containerd specs, in one PR against `opencharly/opencharly`. Three files change; no code, pins, schemas or behavioral config change.

- `CONTAINERD.md` gains §3.1.1, the narrow seccomp profile. It is generated from the installed containerd's `DefaultProfile(spec)` plus `{"names":["unshare","clone"],"action":"SCMP_ACT_ALLOW"}`, with `clone3` left `ENOSYS`, and installed at `/etc/containerd/seccomp/crabbox-userns.json`. A `CLONE_NEWUSER`-only rule is not enough because Chromium still hangs; `keyctl` and `mount` stay `EPERM` as the narrowness control; `kernel.unprivileged_userns_clone` must be `1` where the sysctl exists. The A/B is three-way: the stock profile, this profile, and `unconfined` (RDD7 C10).
- `LIBKRUN.md` gains §10 "Versions". libkrun 1.x is the pin because libkrun `main` (2.0) removes `krun_set_vm_config`, `krun_set_gpu_options` and `krun_start_enter`, which crun's krun handler resolves. crun 1.30.1 cannot start passt at all (`HANDLER_CONFIGURE_AFTER_MOUNTS: start passt`, rc 1), and passt plus in-guest CRIU need a crun carrying `ca04fdb6` and the `/proc` remount (`src/libcrun/handlers/krun.c:824-838`), so that path is main-only until a release ships both (RDD7 S3/B.5, RDD8 T8). The baseline paragraph points at §10.
- `CONTAINERD-IMAGES.md` gains §2.1, the lease readiness hook. An image MAY ship `/usr/local/libexec/crabbox/ready`; the consumer runs it over SSH after SSH readiness, polls until exit 0 or timeout, and reports the elapsed time. The k3s images MUST ship it, checking node `Ready` and a workload exec through apiserver to kubelet, because a fork is `Ready` about 8 s before it is workload-usable (RDD8 T6/N13).
- `CONTAINERD-IMAGES.md` renames every `crabbox-lease*` image to `pod-crabbox*`: 12 image names, 14 prefix occurrences, no "formerly". It states every lease image is CachyOS-based with its own `pod-crabbox-<variant>` repo and its own GitHub Action; makes §1's CachyOS host box the one built now, with other distro boxes additive and each needing its own bed; states the uniform `default` containerd namespace and its single settings/per-deploy override; repoints the §1.1 seccomp row and the §1.3 libkrun row at the new spec sections; repoints §3 rule 6 the same way; and renames the two §5 bed rows.
