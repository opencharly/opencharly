# 2026.311.1323 — docs(design): there is one pipeline runner, and the engine is its implementation (batch 60)

## Summary

Batch 60 of the DESIGN amendments (tracked in #838). `workflow:lobster` was an alternative workflow **engine**
offered as a registry entry. The design says the opposite in its own words:

> §15.1 — `charly pipeline run <name>` runs one; **there is no second runner**

and `_subsystem` has no workflow row. So the engine becomes the **pipeline kind's own implementation**: no
alternative engine can be provided, and the engine's own workflow surface does not enter the registry.

**That is a decision the document already made and never wrote into A.9.** A.9 records it now, and the row takes
`accept retirement`. No schema change was needed.
