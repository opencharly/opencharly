# 2026.261.0521 — feat(opencode): reserve 100000 tokens for compaction

## Summary of changes

Set the opencode `compaction.reserved` token buffer to `100000` in the umbrella's root `opencode.json`.

- `opencode.json`: adds a `compaction` block with `"reserved": 100000`.

**Why:** `compaction.reserved` is the token window opencode leaves free when it auto-compacts a full session so the compaction itself does not overflow. Per the opencode config docs (<https://opencode.ai/docs/config/>) the `compaction` block takes `auto`, `prune`, and `reserved`; `reserved` is the token buffer for compaction.

**Closes / relates to:** none.
