## The file change, the base merge, and the findings this wave raised

**`scripts/check-harness-config.mjs` — the fixture's corpus oracle.** The self-test builds
its corpus inventory from the `marketplace` checkout, then runs the gate against a staged
copy. It asked the filesystem "is there a directory here", while the gate itself asks "does
this directory HOLD a `SKILL.md`". After the corpus retired nine cards, nine empty
directories were left behind in the checkout (git tracks no empty dirs, so nothing reports
them) and the fixture turned them into skills the corpus does not have — 361 against the
real 352 — so its unmutated copy went RED while the live tree was GREEN, and the ratchet's
four units of slack then hid its own discrimination arm. The oracle now uses the gate's own
definition, and `stage()` plants one empty skill directory inside a real family so the
base-green arm proves the guard on every run. *Missed control:* the fixture measured a
filesystem artifact instead of the corpus. *Blast radius:* any session running a pin wave
after a corpus retirement, and a routing regression of up to four rows hidden by the slack.
The ceiling itself (`MAX_UNROUTED = 222`) had already landed with #1267; this branch keeps
that one statement verbatim and adds only the oracle fix.

**The base merge.** While this wave was in review, another session's wave landed as #1267
from the same corpus. `origin/main` was merged into this branch — never a rebase — and the
two conflicts were resolved by "the strictly newer pin wins, proven by ancestry":
`plugin-marketplace` kept this branch's `4c82ccb7` (#1267's `a8881e82` is its ancestor, so
keeping the branch's is the forward move, not an overwrite), and the `MAX_UNROUTED` comment
kept #1267's landed text verbatim so the ceiling has ONE statement. The wave was then
re-run on the merged tree, which advanced `charly`, `sdk` and `spec` again; every path
outside those three now matches `main`, and the evidence table above proves each of the
eight is the remote default-branch HEAD at table-generation time.

**RCA — the pre-push DESIGN finding.** The first push was blocked by `design-pintag` with
ten rows of `untagged … this path has NO checkout, so the tag map came from the clone
shared store`. *Mechanism:* the ten pins were unmaterialized, so the control read tags from
a store that had not fetched the tags minted after it — the pins are tagged; the reading was
