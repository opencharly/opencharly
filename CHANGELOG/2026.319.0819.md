# 2026.319.0819 — feat(tooling): the reconcile can emit the Files-changed table from the diff

## Summary

The body-treadmill this session kept paying for, fixed at the source: **`--emit-table` prints the `## Files changed` table FROM THE DIFF.**

Eleven review rounds across this wave were body-accounting: a table missing a file, a path without its module prefix, a row copied from another repo's diff, a stale stat. Every one of them is a table that could have been generated instead of typed. `--emit-table` runs `git diff --name-only` over the same range the reconcile compares and prints the table, so an author pastes exactly what the checker will check.

**It is one command, not one definition.** The checker still does the comparing — this only produces the input — so there is no second source of truth (R2).

| file | what changed |
|---|---|
| `scripts/check-pr-body-diff.mjs` | `--emit-table`: the table from `git diff --name-only`, plus its `--self-test` arm |
