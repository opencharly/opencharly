# 2026.327.1422 — fix(guidance): qualify the issue-labels reference so the docs link gate resolves it

## Summary

The docs site's generation failed on the new taxonomy guidance:

```
charly docs: 1 unresolvable cross-reference(s) in the skill corpus:
  references/issue-labels.md
    referenced from: recipes/internals/repo-setup.md
every reference must resolve to a defined skill or reference file
rc=1
```

Root cause: the docs generator resolves a bare `references/<stem>.md` token **against the skill that names it**. `repo-setup` wrote the cross-skill path literally, so the generator looked for `repo-setup/references/issue-labels.md`, which does not exist — the page lives under `git-workflow`. `AGENTS.md` carried the same literal token.

Fix (two surfaces, two lines): both now name the owning skill and its reference page in words, with no relative path token —
- `.agents/skills/repo-setup/SKILL.md`: "are in `/charly-internals:git-workflow`, under its issue-labels reference page."
- `AGENTS.md`: "`/charly-internals:git-workflow` (its issue-labels reference page)."

No content changes: every rule, value and example stays exactly as landed in `#1242`; only the cross-reference spelling changes.
