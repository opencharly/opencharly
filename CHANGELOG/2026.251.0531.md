# 2026.251.0531 — fix(agents): eval-runner full-evidence + never-leave-VM; cold-reader artifacts-only

## Summary

Approved workflow-design amendments (plan plan/eval-omarchy-pi-plugin.md §THE WORKFLOW) to three agent contracts:

1. **omarchy-eval-runner**: owns the FULL evidence evaluation — the PR code/diff, check results (summary.yml + per-step logs), the asciinema screencast (.cast text), and the media frames/video — assembling the complete evidence packet (both recording lanes non-empty, rule 6) — plus a MANDATORY cleanup clause: never leave a VM running when done (probe-fail VM and eval teardown both destroyed + domstate-gone verified; zero residual domains or golden locks at handoff; a leftover VM is a runner defect).
2. **omarchy-cold-reader**: explicitly ARTIFACTS-ONLY — re-evaluates everything from the available artifacts (report draft, plan, summary.yml, logs, .cast, media via vision) and NEVER from a running VM (the runner has torn everything down; consulting a live system would be a contract violation). Every claim must reference an artifact.
3. **omarchy-eval-supervisor**: lane concurrency default changed to ONE EVAL LANE PER CPU CORE (concurrency = nproc, capped so 2G × lanes ≤ host RAM — this host: 16 cores → 16 lanes), replacing the hardcoded "16 lean lanes concurrent" wording (this change is the amended accounting: it landed in commit 510baeb after the original body was written).
