# 2026.322.1511 — fix(gates): the table-cell finding names its file and its remedy

## Summary

The `shape` control (design-check's 7th stage) reported a table-row cell-count mismatch as

```console
FAIL :860: a table row has 6 cells where its table has 5
```

— **no file name and no remedy**. Two defects in one message:

- the awk printed `FILE`, an unset user variable, instead of awk's built-in `FILENAME`, so
  every finding read `FAIL :<line>:` and the author could not tell `DESIGN.md` from `TODO.md`;
- a row that split because a `|` inside a code span is still a cell separator — the CUE
  bottom literal `_|_` quoted in a TODO table row is the common case — gave the author
  nothing to act on. A teammate lost a session to exactly this, then two more runs to
  unrelated causes.

**The fix (message only; the judgement is unchanged):** `FILE` → `FILENAME`, and a new
`code_pipe()` detects an UNESCAPED `|` between backticks and appends the remedy:
*a `` `|` `` inside a code span is STILL a cell separator; escape it as `` \| `` (the CUE
bottom literal `` _\|_ `` is the common case)*.
