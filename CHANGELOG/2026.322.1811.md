## Summary

TODO 14.1 (D-CODE-1, D-LAW-5) had no gate: `time.Sleep` sits at five non-test sites in
`charly`/`sdk`/`spec` and nothing judged them. This lands the gate those rows ask for, as ONE
contract: `scripts/check-code-rules.mjs` — every non-test `time.Sleep` must be an
**allowlisted, BOUNDED readiness wait**, the row's own "readiness-wait allowlist".

**The rule is DESIGN.md's, not a guess.** D-LAW-5 (DESIGN.md:41): "… no blind retry or sleep.
… A wait is a declared readiness condition with a deadline." D-CODE-1 (DESIGN.md:2646): "no
`sleep` outside the sdk readiness waits, no retry loop, no suppressed error; a gate enforces
it." The allowlist carries the five sites, each with the bound its enclosing function
declares, and an **exact site count**:

- `charly/charly/plugin_activity.go` — TEST SEAM, `pluginActivityTouchGate` zero in production
- `sdk/agentkit/store.go` — `flockBounded`, bounded by `storeLockTimeout`, fails naming the holder
- `sdk/deploykit/enc_passphrase.go` — poll bounded by `EncMountDeadline`, fails listing remediation
- `spec/lock/filelock.go` — `AcquireFileLock`, bounded by `timeout`, fails naming the holder
- `spec/refs/git.go` — `runGitOp`, bounded `gitOpRetries`, each attempt under its own context timeout

Not a syntactic "bounded in the same scope" test: the bound is a property of the enclosing
function and a regex cannot prove it; the allowlist makes the claim reviewable in one place
and EXACT (a second sleep in an allowlisted file fails, a vanished site fails, an unlisted
site fails — a ratchet with slack would pass all three). Out of scope, visibly: `*_test.go`
waits and commented-out lines; a light worktree with no submodule checkout prints a SKIP —
never a silent pass, and never a false judge of the umbrella's own HEAD (the scan requires
each dir's git toplevel to BE the repo, and it names the revision it judged).

Wired so it runs: `hooks/pre-commit` runs it on every commit; `scripts/self-test.sh` runs its
self-test with the other gates'; `charly.yml` gains a `code-rules` task (gate + self-test
through the verb surface).

**Round 1 (validator BLOCK) findings.** Finding 2 is FIXED in `2241529`: `judge()` now returns
the text it emits and the missing-checkout arm asserts the `SKIP` LINE itself (present there,
absent in every other arm), so deleting the skip message turns the self-test RED — planted and
