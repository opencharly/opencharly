# 2026.323.0032 — docs(policy): number rules 4 and 5, and count the section honestly

## Summary

`PROGRAM/wave-gate-policy.md` numbered its rules **1, 2, 3, 6, 7**. Rules 4 and 5 existed — as the two
closing paragraphs of rule 3 — so a cross-reference to either one resolved to nothing.

```console
$ git show origin/main:PROGRAM/wave-gate-policy.md | grep -cE '^\*\*[0-9]\.|^## Rule [0-9]'
5
$ git show origin/main:PROGRAM/wave-gate-policy.md | grep -nE '^\*\*[0-9]\.|^## Rule [0-9]'
90:**1. An identifier comes from the command that produced it.**
92:**2. A zero needs the control that would have found the word**
99:**3. A deletion's proof is the absence of READERS, not the absence of the name.**
109:## Rule 6. A proof is only as wide as the instrument's reach …
129:## Rule 7. An artifact that was generated records which generator built it …
```

**Five numbered rules on `main`, and the jump from 3 to 6 is the defect.** The two paragraphs between them
carry the content but no number:

```console
$ git show origin/main:PROGRAM/wave-gate-policy.md | sed -n '103,107p'
**And the sharper form, which cost a withdrawn PR:** *the thing that would have stopped you was inside
the diff.* … **Prose that explains why a thing exists is load-bearing …**
**And the methodology that produced the session's best find:** *write the control first, then let it
tell you what the row is.* …
```

**After this change — seven, numbered 1–7 with no gap:**

```console
$ git show HEAD:PROGRAM/wave-gate-policy.md | grep -nE '^\*\*[0-9]\.|^## Rule [0-9]'
90:**1. An identifier comes from the command that produced it.**
92:**2. A zero needs the control that would have found the word**
99:**3. A deletion's proof is the absence of READERS, not the absence of the name.**
105:**4. Prose that explains why a thing exists is load-bearing, so a change that deletes it owes an argument, not a movement.**
107:**5. Write the control first, then let it tell you what the row is.**
109:## Rule 6. A proof is only as wide as the instrument's reach …
129:## Rule 7. An artifact that was generated records which generator built it …
```

**And rule 6 pointed at one of the missing numbers**: *"This is the generalisation of rules 2 and 5"* —
a cross-reference to a rule the document did not carry. That is the same defect that closed four PRs
earlier when a body cited `#1107` after `#1126` had superseded it: **a pointer into a document that does
not contain the target.**

Both are now numbered in their own right, in the same `**N.**` shape as 1–3:

- **Rule 4** — prose that explains why a thing exists is load-bearing, so a change that deletes it owes an argument, not a movement.
- **Rule 5** — write the control first, then let it tell you what the row is.

And the section header said **"Three rules"** over what is now five; it says five.

**No rule's content changed** — only its number and the sentence that opens it. The two that were
subordinated are the two least obvious lessons in the file, and they are now addressable.
