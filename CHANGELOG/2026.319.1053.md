# 2026.319.1053 — docs: restructure the umbrella README around the reader, not the repo list

## Summary

`README.md` is rewritten from scratch — 1119 lines replacing 806 — around the reader instead of
around the repo list. Tracking issue: #1045.

Five moves:

1. **An intro that says what the project is.** candy → box → candybox, the five grievances and the
   one property they compose into, the bet (secure the room, not the candy), and how it is built
   (a small kernel, every capability a plugin, CUE carved once and generated into Go).
2. **A product loop.** `Build → run → deploy → evaluate` as a table plus one short subsection per
   stage. This also closes two dangling pointers: `VISION.md` cites README sections
   `"Build → run → deploy → evaluate"` and `"Build"`, and neither heading existed.
3. **An index of this repo's own documentation.** Every tracked markdown file outside `CHANGELOG/`
   is referenced — split into guidance (identity, rulebook, programme docs, harness bindings),
   skills and agent definitions, technical specs, and history — and `CHANGELOG/README.md` states the
   history convention.
4. **The org map, grouped twice.** A 9-row class table (class · prefix · count · what it holds)
   places every class, and the 40 sections below it group all 392 repos. The small classes keep a
   real `role` column; the three large ones — 161 candy layers, 119 plugins, 72 pods — are grouped
   by theme into 17 + 8 + 9 sections, because the old role column said "image layer / candy" for
   almost every row and carried no information the repo name did not.
5. **The development gist at the bottom**, where a reader who has decided to work here needs it:
   bootstrap, the clone shapes, the one rule (never edit a submodule) with the landing lifecycle, and
   the maintenance table.

The org map is **generated** from `.gitmodules` with a completeness assertion — 392 assigned, no
duplicate, nothing unassigned — so every `N repos` claim and every row is true by construction
rather than by counting. That is the failure mode the hand-typed tables had.
