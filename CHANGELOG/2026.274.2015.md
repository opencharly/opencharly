# 2026.274.2015 — feat(opencode): session issue/PR tracker plugin + durable ledger (rule 11)

## Summary

Adds the OpenCode **session tracker plugin** — the mechanism for AGENTS.md rule 11 on this harness — plus the guidance that says when and how to use it.

**Why.** Rule 11 requires a durable ledger so an interruption never drops in-flight work, and names two branches: a structured **todo primitive** when the harness exposes one, else a durable file. **OpenCode V2 exposes no todo primitive** — verified against the binary: `todowrite` survives only as a migration shim that maps it into the tool-removed list; there is no todo table, no `/session/:id/todo` endpoint, and no `todo.updated` plugin event. So the durable-file branch is the only honest one, and nothing implemented it — the in-flight state lived only in the conversation.

**What changed:**

- **`.opencode/plugins/tracker.ts`** — three tools, PURE TypeScript (no `.sh`, no `spawnSync`/`Bun.spawn`, no `marketplace` pin — the #302 directive):
  - **`tracker_ledger`** — the durable ledger (`read` / `reconcile` / `replace`); rule 11's four categories (`subagent | pr | issue | blocker | op`) + the issue↔PR↔slug binding, at `.opencode/ledger/<session>.json` (git-ignored). **`reconcile` MERGES** — an interruption ADDS, it never resets.
  - **`tracker_status`** — joins the ledger against LIVE GitHub: each scope's real state and the LATEST coordination verb (`OWNING`/`TAKING OVER` wins) with its `Agent:` slug; flags a scope owned by another slug.
  - **`tracker_sync`** — reconciles `merged` (unblock) / `closed` (find successor) / `stall` (takeover candidate); `watch: true` is a BOUNDED one-shot wait on the shared loop.
- **`.opencode/lib/watcher-loop.ts`** — **R3 extraction**: the detached V2 watch loop (session-id capture + `ctx.session.synthetic` delivery + the poll loop + the arm-report + rate backoff), and **`.opencode/plugins/pr-watch.ts` now IMPORTS it** (its inline copy is DELETED). The loop is defined ONCE and shared by `pr-watch.ts` and `tracker.ts`.
- **`.opencode/plugins/coord.ts`** — now OWNS the canonical verb/footer parser: `VERB_RE` **derived from `VERBS`** (the closed set's one owner), plus `parseVerb`/`parseAgent`. `tracker.ts` reads through them instead of re-hardcoding the alternation.
- **Guidance** — `AGENTS.md` rule 11 (mandate + which branch) and the R0 dispatcher row; `.opencode/instructions.md` (the harness binding: tool names, args, the WHEN table); each tool's `description` states when to call it.
- **`.opencode/.gitignore`** — `ledger/`; **`charly.yml`** wires `scripts/check-issue-tracker.mjs` into `verify`.

**R3 — no duplication:** verb grammar/footer is the ONE `coord.ts` parser; the poll engine reuses `lib/watch.ts`; the watch loop is the ONE `watcher-loop.ts`; a claim/resolve reuses `coord_comment`. The tracker IMPLEMENTS the rules and links to their owners — it never restates the verb table, the footer spec, or the rule text.
