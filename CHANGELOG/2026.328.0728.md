- **pod-strata → v2026.328.0334** — the consumer release: composes that tag and proves the deferred start on a disposable GPU pod (`strata-default-lazy-start` reads the server's own startup block, so an eager start fails), plus the first-request load, the five-minute idle release and the reload (opencharly/pod-strata#9).
