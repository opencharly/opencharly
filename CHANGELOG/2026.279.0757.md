# 2026.279.0757 — chore(harness): drop the pi agent config from the umbrella

## Summary

Drop the pi agent config from the umbrella. The operator decided pi should be a
system-level harness (configured under `~/.pi/agent`), not a per-repo surface, so the
committed project pi config and every surface wired to it are retired.

- delete `.pi/` — 16 tracked files: `README.md`, `settings.json`, `APPEND_SYSTEM.md`,
  `claude-plugins.json`, `fabric.json`, `lsp.json`, `vision.json`, the 5 under
  `agents/`, and the 4 under `extensions/`
- delete `scripts/check-pi-gates.mjs` — the regression gate for `.pi/extensions/charly-gates.ts`
- `charly.yml` — drop the `verify` `check-pi-gates` check, the `omarchy-agents` task
  (gated `.pi/agents/*`), and the `pi-forks` task (synced the upstream forks that fed
  `.pi/settings.json`)
- `scripts/check-harness-config.mjs` — remove the pi arm from the MCP + SOUL surface
  sets and the `.pi` self-test surface/mutation
- `scripts/check-root-refs.mjs` — drop `.pi/extensions/charly-gates.ts` from `SURFACES`
- `hooks/pre-commit` — drop the `check-pi-gates` invocation
- reword the surviving pi references: `README.md` (pi packages, maintenance table,
  harness list), `.gitignore` (`.pi` ignore block), `.reasonix/soul-inject.sh`,
  `.opencode/plugins/umbrella-gates.ts`

Removing the pi binding of the git-workflow guardrail (`.pi/extensions/charly-gates.ts`)
and its regression gate is a T4 change; a maintainer-account sign-off is posted on this
PR. The canonical guardrail mechanics are unchanged: `.claude/hooks/pre-commit-gate.sh`
+ `.claude/hooks/pre-push-gate.sh` (wired in `.claude/settings.json`) and the
`hooks/pre-commit` backstop remain.

Out of scope and kept: the vendored pi package submodules (`pi-asciinema`, `pi-fabric`,
`pi-lsp`, `pi-review-action`) and the `layer-pi-agent` / `plugin-agent-pi` submodules.

Closes #385.
