# 2026.319.1037 — fix(pre-push): the reader-independence arm fires on a diff shape, not on a stated diffstat

## Summary

Arm DI in `scripts/check-pr-body-diff.mjs` — `checkDiffCountIsReaderIndependent` — compares the
diff's line count under `myers`/`patience`/`histogram`/`minimal` and fails on any disagreement. It
ran **unconditionally**, while its own message and its own rationale are about a count the **body**
publishes. Unconditional, it is a different and much stronger rule: *no pull request may carry a
diff with a moved block*.

That rule cannot be obeyed when the moved text is pinned **verbatim** by other gates, which is
exactly what a restructure moves. The `## The org map` … `## Pinning` slice, the clone-shape table
rows and the four pin-scope surfaces are byte-identical requirements of `charly task org-map`,
`check-readme-measurements` and `check-pin-verb-scope` — so the remedy the message named, "reshape
the diff", was unavailable, and the only remaining move would have been a hook bypass, which is
forbidden. That is the defect this fixes: the arm now follows the claim it is about.

Measured on the restructure it blocked (opencharly/opencharly#1045): myers 1029/716, patience
1076/763, histogram 1068/755, minimal 994/681 — while an INSERT-ONLY variant of the same rewrite
counts 191/12 under all four, which isolates the moved text as the cause rather than the size of the
change.

| file | what changed |
|---|---|
| `scripts/check-pr-body-diff.mjs` | `statedDiffstat(body)` reads git's own summary wording (`N insertions(+)` beside `M deletions(-)`); arm DI returns INAPPLICABLE — named in the report — when the body states no such pair, and keeps failing, now naming the stated numbers, when it does. The self-test's RED case states a count, and a new scope arm proves the INAPPLICABLE direction can fail. |

The diff of this change is 93 insertions(+) and 11 deletions(-) — one number under every reader,
which is also why the arm's OK direction is exercised on a real body here.

## How tested

The gate that owns this change is the changed path itself, executed live: `check-pr-body-diff.mjs`
run in its `--self-test` mode, which builds fixture repositories and drives the whole gate against
them, on the committed tree this PR publishes.

```
$ git rev-parse HEAD
4dde8b3dea71ae90c4ec5a9dc4449f7bf0bed6c5

$ node scripts/check-pr-body-diff.mjs --self-test
  PASS  a body STATING one of the two counts turns the reader-independence arm RED (myers 29/10, histogram 32/13)
  PASS  a body that states NO diffstat makes the reader-independence arm INAPPLICABLE on the same divergent diff (the rule follows the published count, not the diff's shape)
check-pr-body-diff --self-test: OK (46 arms live)

$ git diff --numstat --diff-algorithm=<each of myers, patience, histogram, minimal> origin/main...HEAD
myers      93/11
patience   93/11
histogram  93/11
minimal    93/11

$ git commit   (the clone-level gate)
pre-commit: OK
```

Both directions are proven, and the RED one is the SAME moved-block fixture as before: the arm still
refuses a stated count on a diff two algorithms count differently. The new arm is what makes the
conditional itself failable — the same divergent diff goes green only because the body states no
count, so a future widening back to "every diff" turns it red.
