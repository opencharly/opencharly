**The umbrella HOLDS the org's repos.** AGENTS.md Part II #2 says the umbrella "pins every OpenCharly repo as gitlinks", and Part II #3 calls the umbrella's own wave over exactly those pins "an ORG-WIDE cutover, not a way to move one pin: it advances EVERY pin the repo declares". So "every repo of the umbrella" is the ORG's repos — a sweep over them is the org's set, and a claim that names the umbrella's command over that set is false in every repo but one, exactly as the unscoped form is.

**THE OBJECT DECIDES IT, NOT THE BINDER.** A binder ties a swept object back to ONE repo, and only a COPY of one repo is one repo ("a clone of the umbrella"). The repos a repo HOLDS are a set of their own, so tying a sweep to them does not narrow it. The bound noun does not decide it either: "of the org" was never a binder, and "of the umbrella" binds a copy, not a member repo.

So the binder now binds only a copy: the scope set's swept form and the marker's binder exception name the SAME copy object and the SAME binder constant (R2), so a sweep the scope set calls a scope is never also a marker, and the two sets cannot drift apart.
