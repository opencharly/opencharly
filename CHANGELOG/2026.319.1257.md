# 2026.319.1257 — feat(pins): track pod-qwen3-tts in the umbrella (org map + gitlink)

## Summary

The umbrella did not track **`opencharly/pod-qwen3-tts`** — the Qwen3-TTS provider repo created during this
work, which now has a merged, tagged history (`v2026.319.1119`). This PR makes the umbrella track it, the
way every other `pod-*` repo is tracked:

- **`.gitmodules`** — `[submodule "pod-qwen3-tts"]`, `path = pod-qwen3-tts`,
  `url = https://github.com/opencharly/pod-qwen3-tts.git`, `branch = main`.
- **gitlink** — pinned at that repo's `main` HEAD (`6d1ae92`, the CHANGELOG commit for its first tag), so
  the pin is a MERGED ref and the currency question has a remote-verifiable answer.
- **README org map** — the row in *Pods: services*, that section's count `12 → 13`, and the header census
  `(392 today) → (393 today)`.

No path is edited inside a submodule: this changes only the umbrella's own gitlink, `.gitmodules` and
`README.md`.
