# 2026.281.0829 — fix(hooks): the pre-commit gate must not demand a charly build a worktree cannot have (+ goal-budget rule 10)

## Summary

Three execution defects that block every DSH session developing opencharly, found by hitting them, RCA'd at the mechanism, and fixed at the root. Two land here; the third is filed.

**1. `hooks/pre-commit` demanded a charly build a worktree cannot have.**

It resolved the binary only at `$ROOT/charly/bin/charly`, where `ROOT` is `git rev-parse --show-toplevel`. In a **linked worktree** that is the *worktree* path — and the hook's own comment and its remedy message both said *"once per clone"*, which is false for the tree AGENTS.md Part II rule 2 **requires** every session to edit in. Result: **every fresh worktree died at commit** until it paid a full charly bootstrap — docs-only commits included. Measured here: `.worktrees/lead/opencharly/charly/bin/charly` absent; the main clone's present.

Now: this tree's build first (R9: binary equals source), then the **main clone's** (reached through the common git dir), announcing itself when it is a fallback; and when neither exists the charly-backed assertions are decided by **change class** — a gitlink change (`task policy-b`) or anything under `charly/` (`task self-test`) **fails closed** naming the candidates and the fix, while a diff charly cannot judge is **skipped with a loud NOTICE** naming exactly what was skipped. Never a flag: there is still no bypass (R6).

**2. The gitlink test had the defect it was written to prevent** — caught by proving the branch, not by reading it. `grep '^:160000'` misses `:000000 160000` — a submodule **added**, i.e. a pin bump, which is precisely what `policy-b` judges. It now matches `160000` in **either** raw mode field.

**3. `AGENTS.md` Part II rule 10 + `.dsh/README.md`: the goal budget.** RCA: this session's campaign was created with `max_goal_rounds: 40` for a 76-issue objective needing ~150–250 owner turns — **6.4× below** the harness default (`dsh-goal/lib/index.js:588` → `Config.defaultMaxGoalRounds = 256`) — and `dsh-goal-round-driver` blocks **hard** at the cap, phase `blocked`, goal **disarmed**, with **no warning phase**. The root fix is guidance, not configuration: the knob already had a sane default. Rule 10: size the cap to the projected owner-turns, never below the default without a stated reason, and at ~80% of budget with work remaining **STOP and ask the operator** instead of narrating an ending.

**Routed, not deferred (R2/B13):** the `charly task` worktree-loading defect — it dies with `json: unsupported value: encountered a cycle via map[string]*spec.UnifiedFile` instead of naming the precondition — is filed as **opencharly/opencharly#428** and routed to the **C1 gate-plane batch** (owner: `harness-bindings`, whose C1 remainder this session assigned it), which is the thematic batch that carries product-surface diagnostics for the mandated worktree workflow. It is not fixed in this PR because this PR is the hook's own cutover and the two surfaces are separate repos' concerns.

## The premise the skip rests on, established here

The added skip is scoped by what the two assertions can actually judge, and each half is named with its basis rather than asserted:

- `charly task policy-b` is the hook's own `verb:git-submodules verify` — it judges **gitlink** state, so a diff that changes no gitlink cannot violate it. The diff establishes this by **failing closed** on exactly that input: with a gitlink staged and no binary anywhere, `needs_charly=1` and the hook exits 1 naming the candidates (case (c1) below); an *added* submodule (`:000000 160000`) is matched, which is the pin-bump case the first version of my test missed.
- `charly task self-test` exercises **charly's own** CI body/pin-evidence builders, so only a diff under `charly/` can invalidate it — and that input also fails closed (case (c2)).

So the skip is not a flag and not a bypass: it fires only for diffs that touch neither input, prints a NOTICE naming exactly what was skipped and how to enable it, and both judged inputs take the fail-closed path.
