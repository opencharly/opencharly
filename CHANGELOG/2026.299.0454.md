**The finding.** The validator's words: *"the tilde-fence arm passes its fenced fixture via the `claim` positional slot rather than the `evidence` slot — functionally the scanner still catches it because `checkEvidence` scans fences body-wide, but it is slightly off-intent."* The arm named *"the body pastes evidence in a TILDE fence"* while its fixture put the tilde fence in the Change classification section. The arm still caught the stale line, but an arm that does not exercise the path it names is not proof of that path, and the merged test could not state the guarantee at all: the fixture's evidence block was a fixed backtick fence, so a tilde-rendered evidence block — the shape a real body has — was not expressible.

**The fix.** The fixture's evidence block takes a fence **character**, so an arm can render that block with tildes. The tilde arm now drives the evidence slot it names, the prose placement becomes a second arm named for what it does, and a green arm the merged test lacked — a closing directive inside a **tilde** fence is evidence, not a directive — is added.

**This pull request changes NO behaviour of the gate, and that is measured, not asserted.** The merged gate (`f893b4c`) and this branch produce **identical output on all eight** fixture bodies. What it changes is the SELF-TEST: the merged test could not state the guarantee that a tilde-rendered evidence block is judged by the evidence arm, and now it does — the new arm is a regression guard for the tilde-awareness #703 brought, and the merged gate already satisfies it.

**The validator's second observation** — that #703's body pasted 21 of its PASS lines under the label *"the new ones among them"*, so a reader could take the selection for the whole transcript — was a defect in that pull request's **body**, not in its code. It is corrected on #703 itself, which now describes the change that was actually merged.
