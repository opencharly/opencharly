# 2026.288.2134 — docs(program): create the promised PROGRAM/ surface, with its convention (resolves #493)

## Summary

Creates the **`PROGRAM/`** surface the rulebook promises, with the convention it was missing. One new file, 59 lines.

```
AGENTS.md:643  - `SOUL.md` — identity; `VISION.md` — thesis and direction; `PROGRAM/` — binding
                 program north stars.
```

Three of those four surfaces existed. `PROGRAM/` did not — and it is the **only** promised home for a programme document, so a programme ledger had nowhere rulebook-sanctioned to land. The surfaces that do exist are each wrong for one: `CHANGELOG/` is history, a skill is usage, `README.md` is the user overview, `AGENTS.md` is the mandate. Filed as `opencharly/opencharly#493`, which this PR resolves.

**Nothing in the rulebook changes.** The pointer was already written; this makes it *true* rather than dangling. The convention document states what belongs there (programme ledgers, north stars, cross-repo cutover plans, dated post-mortems), what does not and where it goes instead, how entries are named and shaped, and the lifecycle — current rather than historical, updated in the same change that moves the work, corrections stated rather than edited away.

It carries no programme content of its own: the first real entry is the one that needed the surface. If the intent is instead to drop the pointer, or to aim it at an existing home, that is a one-line answer and this directory deletes with it — `#493` offers all three options and I chose the one that makes the existing text true rather than one that rewrites it.
