# 2026.242.0950 — fix(pi): overhaul the umbrella pi agent config + policy-B sync

## Summary

Fix the umbrella's per-repo pi agent config (RCA'd 2026-08-30) and sync all submodule pins per policy B.

### Pi config fixes

1. **github-pr-status.ts stale-verdict bug (real bug).** The tool fetched `per_page=5` comments, but the issue-comments API returns ascending by default and ignores `direction=desc` — so it scanned the OLDEST 5 comments and reported a stale BLOCK verdict even when the latest verdict was PASS (observed live on charly#474: BLOCK reported while the actual verdict was PASS). Fix: fetch `per_page=100` and scan the NEWEST 5.
2. **Dead agent config → working agents.** `.pi/subagents/umbrella-agents.json` was never read by pi-subagents (agents are markdown files or `subagents.agentOverrides`; the JSON format is dead). The custom reviewer/worker/validator agents were therefore never loaded — delegation fell back to generic builtins. Root-caused the tool-less child issue: the `--tools` allowlist path drops the core builtin tools (read/grep/find/ls/edit/write) in children, while agents with NO tools field inherit the full default tool set. Fix: `subagents.agentOverrides` for reviewer/worker with `tools: "inherit"` (the documented way to give a builtin the full default surface) + a `validator` markdown agent at `.pi/agents/`. Verified live: all three children now resolve `read`/full tools.
3. **System prompt strengthened.** The injected rules block now mandates: (a) ALL issues are fixed — pre-existing or not (R2, no "pre-existing"/"out of scope"/"follow-up PR" classifications); (b) skills are living documents — any code change that affects a skill/doc/comment updates it in the SAME change (R1); (c) use subagents and fabric whenever possible (delegate heavy exploration, batch independent calls).
4. **New umbrella-verify extension.** `umbrella_verify` (the R7 pinning gate, `task verify`) and `umbrella_sync_status` (`task map` pin/sync state) — thin wrappers over the canonical scripts with bounded, structured output.
5. **Package updates to latest.** pi-subagents 0.51.0→0.60.0, @narumitw/pi-plan-mode 0.49.3→0.56.0, @juicesharp/rpiv-todo 2.6.2→2.8.0, pi-claude-marketplace 0.18.0→0.18.1, pi-web-ui 0.50.0→0.54.0.
