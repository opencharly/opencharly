## What the entry adds: the unit pattern, stated once so it can be copied

**Three `deploykit` units have now landed, and every one that did so first-try carried the same five measurements:**

1. **per-file `git diff --numstat`**, and its sum computed by `awk` -- not by hand;
2. **`git diff -U0 origin/main...HEAD`** with the **revision range**, then the comment-only filter -- and a sentence saying why the range matters, **because `git diff` with no range diffs worktree-vs-index and prints nothing on a clean tree whatever was committed**;
3. **the site count from the KEYWORD-FILTERED removed-line count**, never the bare removed-comment count -- on one unit those differ **74 vs 14**, and citing the wrong one is a command for a different question;
4. **the remainder at BOTH refs**, base and head, with the net stated and its operands shown -- one unit's diff removes fourteen matching lines and **adds** one, so the census moves by thirteen and the identity has to close;
5. **`git log --oneline origin/main..HEAD` pasted**, never a count of it -- **six PRs in this session were blocked on their own commit count**.

**Every unit that skipped one of these five took extra verdicts, and every finding that resulted named one of them.**
