# 2026.265.2052 — fix(sync): bound the sync PR body for GitHub's 65536-char cap + retain full evidence

## Summary

RCA fix for the umbrella's automated gitlink-sync tooling: the generated sync PR body overflowed GitHub's **65536-character** limit, so no sync PR could open.

**RCA (live, 2026-09-22).** The org-wide ruleset cutover retired the per-repo dispatcher in every repo, advancing **393** umbrella submodule pins at once. The generated body was ~72 KB (per-pin evidence table ~45 KB + producer slice ~13 KB + path list ~7 KB + boilerplate) and `gh pr create` failed: `GraphQL: Body is too long (maximum is 65536 characters)`. The run pushed its branch but could not open the PR.

**Fix — bound every section, retain the full evidence, make it testable:**

- **`scripts/sync-pr-body.sh` (new)** — the body/artifact builder, extracted from the untestable inline workflow block (the repo's own "testable committed script" pattern). It bounds the path list (`SYNC_PATH_LIST_MAX`, default 200), the producer slice (`PRODUCER_MAX`, default 200), and the per-pin table (via `sync-pin-evidence.sh`), and **hard-guards** the final body against the cap (fails loud naming the byte count). It writes the **full** evidence to the `sync-evidence` artifact file the workflow uploads — including the **full rendered per-pin table** — so the body's elision notice is true.
- **`scripts/sync-pin-evidence.sh`** — extracted `bounded_rows()` (the one byte-bounder, shared by the live path and the self-test): render rows to a temp file, then emit until the budget, always ≥1 row + an elision naming shown/total. `SYNC_EVIDENCE_OUT` appends the full table to the artifact.
- **`.github/workflows/sync.yml`** — the inline body block is replaced by one call to `sync-pr-body.sh`; the `sync-evidence` artifact upload step is added.
- **`hooks/pre-commit`** — runs `sync-pr-body.sh --self-test` alongside the other gate self-tests.
- Fixed a real counter bug the new fixture exposed: `grep -c . || echo 0` emits `0\n0` (grep prints `0` **and** exits non-zero), corrupting the count.
