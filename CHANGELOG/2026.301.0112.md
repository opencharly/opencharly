# 2026.301.0112 — fix(measurements): the corpus's shape is derived, and the gate can see it

Closes #755

## Summary

Head `042201d7126cae0aba287a5885bd8c9300b83645` — the commit this PR pushes: **2 files changed, 84 insertions(+), 20 deletions(-)**.

**The umbrella's measured-figures control could not see the corpus's shape, and the prose it guards carried a second copy of that shape.** `reasonix.toml` headed its derived `[skills] paths` list with a hand-maintained count of the same collection — "42 directories", against the 45 entries the list itself names — and dated that count at a corpus pin (`ac7d97e5`) the branch stopped recording on 2026-10-20. The control installed for exactly this class of claim, the shape-count family in `scripts/check-readme-measurements.mjs`, names no corpus noun: it reads `submodules`, `pins`, `paths`, `modules`, `remotes`, `worktrees`, `calls` and the two materialization states, so a count of `directories`, `skills`, `families`, `rosters` or `SKILL.md` was invisible to it. The control was green over a file whose own comment was false.

This discharges opencharly/opencharly#755 in full, in three parts that are one cutover, because one of them is the reason the other two were invisible.

**The prose stops carrying a copy of a number the list already carries.** The block now states the derivation and not the count: the list is the count of record, and a number beside it is a second copy that drifts. The written pin is gone — a pin moves on every advance, so a written pin is a claim that cannot be kept — and the one figure that survives is the dated point measurement of the corpus this branch pins.

**The control gets the reach it lacked.** The shape-count family's noun list now carries the corpus's own nouns, in their plural form only: the singular of a collection noun names a THING rather than a collection, and a family that read "the `0700` directory" as a count would report this tree as broken. A number is also read WHOLE. A count written with a thousands separator is one number, and the separator used to cut it in two — so a count of 1,000 fell under the floor and escaped the family, while a count of 3,500 was reported as 500, a finding that named the wrong number.

| file | what it changes |
|---|---|
| `reasonix.toml` | the skills comment: the hand-maintained corpus counts and the written pin are replaced by the derivation, and the surviving dated block names the corpus this branch pins |
| `scripts/check-readme-measurements.mjs` | the shape-count family: the noun list carries the corpus's own nouns, a number written with a thousands separator is read whole, and six new self-test arms hold both |
