# 2026.272.0901 — docs(agents)!: rule 11 — itemize subagents, open PRs, blockers, long ops in the ledger

## Summary

Extends rule 11 (`Todo ledger & interruption safety`) with **what the ledger must contain** —
the concrete tracking convention I was missing while being disrupted mid-program. The rule
already said "keep the list"; it never said *what goes on it*, so a disrupted session could
not resume from the list alone.

Adds four mandatory entry classes, one item each:

1. **Every RUNNING subagent** — session id, task, PR/artifact, last observed state. A worker
   with no item is an unmonitored worker.
2. **Every open PR you own or plan to open** — the PR (or `PLANNED`), head, verdict, and the
   single next action (fix / update-branch / sign-off / merge-watch). A PR with no item is a
   PR nobody is driving.
3. **Every blocker** — what is blocked, by whom/what, and the ONE named unblock path.
4. **Every long-running operation** (a bed run, a sync, a batch landing) — so an interruption
   resumes it rather than restarting it.

Plus: when the harness exposes a **structured todo primitive** (a `todo`/`todowrite` tool), it
**IS** the ledger — one todo per item above, reconciled FIRST on every interruption; a durable
file is the fallback when no such tool is exposed.

This is the rule I broke this session: I drove ~30 subagents, ~10 PRs and the `#714` critical
path from conversation memory, and lost the thread twice on interruption.
