# 2026.262.2348 — docs(agents): add rule 9 — session-scoped ownership

## Summary of changes

Adds **rule 9 — session-scoped ownership** to the umbrella rulebook (`AGENTS.md`).

Concurrent agent sessions share this checkout. Each session's changes — the files it authored, the branches it created, the PRs it opened — belong to that session. Rule 9 makes that explicit:

- Never edit, revert, reformat, stage, or commit another session's files, even to "clean up" or unblock your own work.
- A submodule another session left dirty or on a branch stays exactly as found.
- If a file you do not own blocks you, do NOT touch it: communicate through a **PR comment** on the PR that owns the file (or open an issue naming it), and stop and ask the operator if still blocked.
- Leave no uncommitted file of your own authorship behind; an untracked scratchpad is the one exception and is cleaned up before finishing.

**Files:** `AGENTS.md` (+12/−0; `CLAUDE.md` is its symlink).
