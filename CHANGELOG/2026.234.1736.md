# 2026.234.1736 — chore: sync all submodule pins; spec no longer charly-pinned

## Summary

Syncs all umbrella submodule pins after the org-wide landing-flow redesign, and fixes the spec pinning policy.

### What changed and why

1. **Sync all pins** — `charly` → a7f77042 (its default HEAD, includes #375/#376), and the charly-pinned repos (sdk/plugins/docs/distro-*) → exactly charly's gitlinks. `dotgithub` → 44edadd (includes #68–#71), `pi-review-action` → 0f69d85 (includes #6).

2. **spec is no longer charly-pinned.** charly de-submoduled `spec` (charly#371 — it now resolves `github.com/opencharly/spec` from the Go proxy at a pinned go.mod require). The umbrella scripts still required `spec == charly's gitlink`, which fails because charly has no spec gitlink anymore. Fixed:
   - `scripts/sync-gitlinks.sh` + `scripts/verify-pins.sh`: dropped `spec` from `CHARLY_PINNED` (with a comment documenting why).
   - `README.md`: pinning policy — `spec` now follows the every-other-repo rule (own default-branch HEAD, e48dbac).
   - `spec` submodule pinned to its own default HEAD.
