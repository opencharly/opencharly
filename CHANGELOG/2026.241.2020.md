# 2026.241.2020 — feat(pi): keep system-prompt-advertised extension tools bare-name callable via fabric keepVisible

## Summary

The umbrella system prompt advertises extension tools by their bare pi names (`todo`, `create_goal`/`get_goal`/`update_goal`, `subagent`/`subagent_wait`, `gh_pr_status`, `umbrella_load_skills`, `memory_*`, `scratchpad`, `web_search`/`fetch_content`, `team_*`), but pi-fabric full-code mode captures extension tools under `extensions.<name>` and hides them from the model's active tool set — `capture.keepVisible` defaults to only `fabric_exec`. A bare-name call therefore fails with `Tool <name> not found` (RCA: fabric's `FabricToolOwnership.apply` removes captured tools not in `keepVisible` from the active set; the system prompt's tool advertisement comes from pi's registry, which uses bare names — an advertisement/dispatch mismatch).

**Fix:** add `.pi/fabric.json` with `capture.keepVisible` re-exposing the advertised tools as bare-name callable (the documented escape hatch: "adding a name to `capture.keepVisible` re-exposes them"), and document the file in `.pi/README.md`.
