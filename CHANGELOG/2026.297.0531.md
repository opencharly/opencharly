**The fix — the mutation is a LIVE re-run of the assertion.** #656's mutation sub-check did
not re-run assertion T on the mutated text: it regex-extracted `REF` from the mutated
source and inspected the captured string. That proves the mutated SOURCE lacks the token;
it does not prove the ASSERTION goes red on it, and it cannot catch a regression where the
line-builder stopped reading the reference it is handed. So the builder now takes the
reference as a parameter (`okLine(ref = REF)`), the predicate that decides the assertion is
ONE function (`printsOwnToken`), and the mutation hands the **mutated** reference to the
builder and runs the **same** predicate over the result — a live re-run of assertion T on
the mutated input, not a regex over the mutated text.

**The comment now says what is true.** #656's comment claimed the ASCII rendering was
"spelled here in PIECES". It is not present in the file at all: the R5 sweep greps for that
literal, and the gate must not defeat its own sweep.
