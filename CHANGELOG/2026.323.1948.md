# 2026.323.1948 — fix(hooks): refuse a marketplace checkout that is not the pinned linter

## Summary

`hooks/pre-push` runs `marketplace/scripts/pr_body_lint.py` — the **checkout's**
copy — and has a skip for a MISSING `marketplace/` but none for a STALE one. A
checkout that predates the pin therefore enforces an older linter, silently and
with a green result. That is how opencharly/opencharly#1159's malformed footer
came back as a defect 35 minutes after its fix landed: the checkout at
`6f7ec7c` returned `0 finding(s)`, the pin at `69e0842` returned `1 finding(s)`
(opencharly/opencharly#1176).

The hook now asserts the CONTROL'S OWN VERSION before it lints: it compares the
gitlink the INDEX records (`git ls-files -s -- marketplace`) with the checkout
(`git -C marketplace rev-parse HEAD`). A disagreement is a visible BLOCK that
names both commits and the one command that moves the checkout to the pin. The
existing visible skip for an unmaterialized submodule is unchanged; a
pinned-but-not-a-git-repository directory is a new visible skip (the header's
machine-checked count moves 13 → 14, and the gate's own assertion keeps it in
step). A tree that records no marketplace gitlink — a fixture or a fork — has no
control version to assert.

`scripts/check-pr-body-gate.mjs` gains both directions of the control as fired
assertions — a checkout BEHIND the pin is blocked, a checkout AT the pin proceeds
and lints as before — and `--self-test` gains the mutation that deletes the
comparison, which must turn the gate red.

| `scripts/check-pr-body-gate.mjs` | the behind-the-pin and at-the-pin assertions, plus the self-test mutation |

## Change classification

A push gate now blocks when the marketplace checkout is not the commit the index
pins. That is deliberately breaking for a clone whose `marketplace/` is behind
(or ahead of) the index: it will refuse until the checkout is moved to the pin,
which is the point — a pass earned by an older linter proves nothing. Rollback is
the revert of the one hook leg plus both gate assertions.

**Breaking change + rollback:** a stale marketplace checkout now blocks the
push instead of linting with older rules; revert `hooks/pre-push` and
`scripts/check-pr-body-gate.mjs` together to restore the previous behaviour.
