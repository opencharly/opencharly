# 2026.295.0424 — docs(containerd-images): cite the measurements in the cross-cutting rules

## Summary

Carries the one item the reviewer raised on #574's PASS that did not make that head: `§3`
"Cross-cutting rules" reported measurements — the `82 ms` post-reset start, the `94.7 s` that was
a poll budget, the machine-id/MAC collision, and the no-`unconfined` rule — without naming where
each was measured, while the file's opening rule promises a citation for every requirement.

All four now name their source:

| Rule | Cited |
|---|---|
| the inner engine must not start rate-limited (`82 ms`) | RDD8 track T7, item N2 |
| a probe never reports its deadline as a duration (`94.7 s`) | T7, N2 |
| `/etc/machine-id` emptied before a commit; `MACAddressPolicy=none` | `K3S.md` §6–§7; RDD7 N6 |
| nothing set to `seccomp=unconfined` or run `--no-sandbox` | measured, RDD7 C10; `§1.1` of this file |

With this, every requirement in `CONTAINERD-IMAGES.md` sections 1–3 either carries a Source
column (§1 requirement tables), sits in a section whose closing index names its source (§2), or
names its measurement inline (§3).
