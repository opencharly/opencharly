**`.opencode/plugins/agent-progress.ts`** registers **TWO** native V2 tools:

- **`agent_progress`** (MONITOR, read-only) — per session: turns, span, last-activity age, tool mix, the LAST action, artifact hints, and a verdict **WORKING / IDLE / LOOP / DONE**. **A "message" is an ASSISTANT TURN, never a stall signal.**

**Pure TypeScript** — the ONE `execFile` drives the opencode CLI (a tool, like `gh` in `coord.ts`), never a `.sh`; no `marketplace` pin.
