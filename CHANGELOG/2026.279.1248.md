# 2026.279.1248 — fix(harness): name the gates the umbrella's pre-commit hook actually runs

## Summary

Both published descriptions of the umbrella's pre-commit gate were **one change behind the
hook they describe**. This brings them current. Nothing else changes.

- **`charly.yml` — the `hooks` task description said `(policy B + parity)`.** Parity was
  real when `f230518` (#247) wrote it: that commit's own `hooks/pre-commit` listed
  `#   2. harness parity    — the 5 files byte-identical to charly's by design`
  (`charly task harness` → `verb:file-parity`) and ended the gate by calling
  `"$CHARLY" task harness`. `f092c21` (#341 — *"rule 8 reversal"* in its own subject; the
  same content is **rule 5** in today's `AGENTS.md`) absorbed the harness config into the
  umbrella and **deleted the mechanism, leaving the sentence that announced it**. Nothing
  has been compared since: `grep -rn -i parity hooks/ scripts/` returns **0**, and rule 5
  states the position outright — *"no mirrors, no parity gate"*.
- **`hooks/pre-commit` — the header listed four gates; the file runs five.** `cfd30b2`
  (#390) added the pi-gate call to the body without adding it to the list of what the hook
  runs, so a reader learned about four of the five gates it actually runs.

Both now name the five gates the hook runs: policy B, the self-tests, and the opencode, pi
and pr-watch gate scripts.
