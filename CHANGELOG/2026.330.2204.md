# 2026.330.2204 — fix(opencode): type identityError's parameter as the awaited identity

## Summary

Follow-up to #1304, closing its one non-blocking review note. `identity()` became `async` there, so `identityError`'s parameter annotated `ReturnType<typeof identity>` typed the parameter `Promise<Identity>`, while both call sites pass the awaited object. `Awaited<ReturnType<typeof identity>>` restores the true contract.

No runtime behaviour changes: TypeScript types are erased before execution. The fix keeps the type layer honest for the first `tsc` run — the missing type-check control itself is #1305.
