## Summary

than as new charly concepts. Four targets, one change:

  (`#AgentNode`/`#AgentBody`, derived into `_deploymentKind` through `#InnerOfMachineAlt`); **`#Namespace`**
  (a namespace is a named scope, never a kind word or a directive); a manager install carrying its owning
  plugin's input (`#ManagerInput`/`#ManagerPackage`/`#PackageEntry`, `_managerPhase` with the derived
  `_buildManagerWord` and `#BuildManager` — the table's apply-phase rows serve to EXCLUDE those words from the build-time set, so there is no second `_applyManagerWord` to drift); parameterization as a choice (`#InputAlt`/`#Input`/`#Inputs`/

  `#Redacted`); **`#StatusOutput`** with the `admit`/`activate` methods; and `#HostMethodIO` gaining
  `state_commit`/`audit_append`; and `#Error` gains `request?: #CallId` and `detail?: [...#AuditDetail]`, so an
  error carries the same request identity and the same redactable detail as the audit record.

controls: the pinned toolchain (cue v0.17.1, sha256-verified), `DESIGN.md` ↔ `DESIGN.cue` bidirectionally

the change does not hollow out the checker it passes.

**One caveat a reviewer must know:** the first attempt passed the gate while carrying seven contradictions —
the gate proves a design is *self-consistent*, never *complete*, because it checks only the mirrors declared
with `<!-- schema: … -->`. An independent read of the register against the shipped files is what found them.

Proven, not asserted, during the work: the check is green on the pristine tree first (143 s, so any later
failure is this change's); `TestExtractMetadata_HostNeedLabel`-style non-vacuity was applied to each new
negative case (each is rejected **for the right reason**, with the message pasted in
`plan/openclaw-enterprise-ledger.md` §17); and every R5 sweep ended with a **claim-keyed `git grep`** rather
than a replace count — which is how a fifth `agent-run` span, and two silently dropped `TODO.md` rows, were
caught.
