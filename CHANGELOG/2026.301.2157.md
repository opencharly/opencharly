# 2026.301.2157 — fix(gate): the pin-advance verb's scope is EVERY declared path, and no surface may narrow it

Refs #787.

## Summary

Head `38878172c26dacb9e1abf3c84a28f129adde9954` — 4 files changed, 131 insertions(+), 6 deletions(-).

**The defect.** Three of this repo's surfaces stated the pin operation's scope over the
`distro-*` set — in the same line in which they named that it advances EVERY pin the repo
declares. The operation runs over EVERY declared path: the `git-submodules` verb's own
contract covers every path `.gitmodules` declares, and the six `distro-*` paths are the EDGE
subset of them (the `pin_map`), while every other declared path is an ordinary pin. A reader
who trusted the first clause expected the verb to touch that subset alone.

**The RCA.**

- **Mechanism** — the six `distro-*` paths are the only ones the EDGE half of the pin contract
  judges against a source, so the vocabulary of the EDGE ("the `distro-*` set") was applied to
  the whole operation in three surfaces. The verb itself was never wrong; only the statement
  of its scope was.
- **Missed control** — `scripts/check-pin-verb-scope.mjs` asserted only the POSITIVE claim:
  that every claim-maker surface STATES the scope. A surface could state the universal claim
  AND contradict it in the same breath, and the gate stayed green — a positive-only assertion
  cannot see a contradiction inside the line it accepts.
- **Blast radius** — every reader of those three surfaces: the README's maintenance table,
  the manifest's `pins` task description (the task's own one-line contract, printed by
  `charly task list`), and the `git-workflow` family's umbrella-mechanics reference, which is
  projected into the guidance corpus for every harness that loads it. No consumer ran the
  wrong verb; every consumer was told the wrong scope.
- **Root fix** — the three surfaces state the operation's scope over EVERY declared path and
  name the `distro-*` paths as the EDGE subset; and the owner gate gains the missing NEGATIVE
  arm, so no claim-maker surface may scope the verb to a SUBSET.

| file | what changes |
|---|---|
| `README.md` | the maintenance table's `charly task pins` row states the scope over EVERY declared path and names the `distro-*` paths as the EDGE subset |
| `charly.yml` | the `pins` task's description carries the same scope, and the step that runs the gate's self-test names the new discrimination |
| `.agents/skills/git-workflow/references/umbrella-mechanics.md` | the task table's `charly task pins` row carries the same scope |
| `scripts/check-pin-verb-scope.mjs` | the gate gains arm D — no claim-maker surface may scope the verb to a SUBSET — with a `--self-test` mutation that proves the arm discriminates |
