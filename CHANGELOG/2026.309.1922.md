# 2026.309.1922 — docs(design): a reboot is not a step, and the design already says so (batch 46)

## Summary

Batch 46 of the DESIGN amendments (tracked in #838). `RebootStep` reboots a VM venue mid-plan after a
boot-content change. **The ledger's own target for it already says the answer:**

> the build environment restarts by itself on a boot-content change; **no action asks for it**

A reboot is **not a step**. Content that changes the boot makes the environment restart, so nothing has to
ask — and **D-IR-2** keeps every action reversible, which a reboot cannot declare. A.9 records the trade and
the row takes `accept retirement`.
