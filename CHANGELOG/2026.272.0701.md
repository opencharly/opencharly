# 2026.272.0701 — docs(agents): exact subagent lifecycle — one task per worker, rotate on stall, never re-task

## Summary

Add the **exact subagent lifecycle** rule to `AGENTS.md` so it is picked up by **every
harness/opencode instance in this repo automatically** (AGENTS.md is auto-read).

Field evidence: a subagent session ran **7 hours / 351 messages** and produced **no
artifact** on a few-file change — while a **fresh** session with the same brief produced
it directly. The loss was **re-tasking a stalled session** with appended corrections,
which grows context with dead ends and superseded instructions instead of converging.

**The rule added:** one task per subagent (close on completion, never re-task a finished
worker); **rotate on stall** (no artifact after two re-briefs, or ~50 messages → STOP and
spawn a FRESH subagent); **judge progress by artifacts, never liveness**; cap the fan-out;
durable artifacts carry state across the rotation; **do the bounded critical-path fix
yourself** when you hold the context. Mechanism lives in `/charly-internals:agents`.
