**opencharly/opencharly#799 named the gap: the spec knows what is retired, the repos know what they say, and nothing connects the two** — so the sweep was manual, per session, per repo. This lands the seam for THIS repo's tree: one committed control that reads the canonical list from the pinned spec submodule and asserts it against the umbrella's own tracked tree.

**The key set is the CONTRACT'S.** The list is read from `spec/retired/identifiers.json` at the pinned gitlink, and this gate spells no withdrawn name of its own — a gate whose own source carried the names it forbids would have to exempt its own source, and that exemption is a hole. The list's entries carry a SCOPE (a Go type), because a name withdrawn from one surface can be legal on another; a TEXT surface — which is all this tree has — sweeps the UNSCOPED entries only, and the verdict says so with its coverage.

**A hit is not automatically a carrier, and the control says which one it is.** The org's own sweeps classify every hit BY HAND — the corpus's own sweep ships the classification table (history; a counter-instance that denies the name; an explanatory comment that names it; a live claim) — and the distinction is semantic: a sentence that denies a withdrawn name and a sentence that sets its value carry the same name and mean opposite things. A control that reported both as a defect would cry wolf on the org's own correct documentation, and a control that GUESSED the distinction would miss the carriers it exists to catch. So the classification is committed here, in `scripts/retired-records.json`, each entry naming the file, the identifier, the text it covers and WHY. A hit no record covers is a carrier; a record that covers no hit is ITSELF a finding, so the file cannot rot into a hole that hides a live use; and a record covers only the identifier it names, so a record written about one name can never excuse another.

**The walk moves into one library.** The umbrella already carried two copies of "the tracked files of this tree", and they had drifted on what a SYMLINK is — one of them read through the link and judged another repo's content under this repo's rulebook. `scripts/lib/tracked-tree.mjs` is now the one implementation, one scope; `scripts/check-retired-claims.mjs` carried the third copy and now imports the library, so the umbrella has ONE walk and not three.

**The coverage is stated, not claimed.** This gate judges the umbrella's tree and NOT the org's — a submodule is a repo of its own with its own gates — so the org's other repos need the arm that reaches them, and #799 stays open until that arm lands. This PR is the umbrella's leg of it, not the whole of it.
