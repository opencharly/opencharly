# 2026.272.0652 — fix(sync)!: emit the FULL per-pin evidence in the sync PR body (compact rows)

## Summary

Fix the sync-PR **body generator** so it emits the **COMPLETE** per-pin evidence
in the **body** — the `charly/pr-validator` requires it and BLOCKs the live sync
PR `opencharly/opencharly#297` (*"a pointer to an external Actions artifact is a
promise, not pasted output"*).

The body was truncated by two bounds and pointed at the `sync-evidence` artifact:
- `scripts/sync-pr-body.sh`: `SYNC_PATH_LIST_MAX=200` → *"first 200 of 402"*.
- `scripts/sync-pin-evidence.sh`: `SYNC_EVIDENCE_MAX_BYTES=40000` → *"350 of 402 rows shown"*.

**The change (two files, net +136/-82; `git diff --stat origin/main...HEAD`):**

1. **Drop the redundant "Every changed path, named" list entirely and REMOVE
   `SYNC_PATH_LIST_MAX`.** The per-pin evidence table names every moved path
   **and** carries its proof (`staged-gitlink` vs remote default-branch `HEAD`),
   so a second list is redundant bytes. The body now states that, and no
   `SYNC_PATH_LIST_MAX` line remains (R5 — removed, not raised).
2. **Compact the per-pin rows**: `  <path>  <staged12>  <remote12>  <flag>`
   (≈50 B/row vs ≈115). The kind (`distro-*` policy-B vs default-branch) is
   derivable from the path prefix and stated **once** in a one-line legend;
   `flag` is `=` (equal) or `!` (mismatch — a real finding, never silently
   elided).
3. **`SYNC_EVIDENCE_MAX_BYTES` has a single default, in
   `scripts/sync-pin-evidence.sh`, raised 40000 → 50000.** `scripts/sync-pr-body.sh`
   does **not** set the variable, so that single default reaches the renderer —
   it is a **fallback guard only** and does not fire at fleet scale. The stale
   `40000` comment in `sync-pr-body.sh` is rewritten (R5 sweep), and the
   `sync-pin-evidence.sh` bounds comment now cites the **measured** size (≈39 KB
   body / ≈21 KB table), not the earlier ≈45 KB guess (R1/B10).
4. **The `--self-test` asserts the COMPLETE table in the BODY** at a 424-pin
   fleet-scale fixture — row count `==` fleet count and **no elision line** — not
   only in the artifact.
