# 2026.261.1230 — docs(agents): drop the drifting corpus dispatcher row count

## Summary

Removes a drifting hard-coded count from the umbrella's R0 dispatcher prose.

- `AGENTS.md`: the Skill Dispatcher preamble said the corpus's generated dispatcher has "**70 rows corpus-wide**". The actual `marketplace/DISPATCHER.md` has **90** rows now, and had **81** the day the figure was written (the marketplace corpus did not even carry `DISPATCHER.md` on the commit that introduced the number). The number is not asserted by any gate, so it drifts silently. The sentence now names the file as the authority instead of quoting a count.

**Closes / relates to:** a documentation follow-up to `#210` (which introduced the table and the number).

**Breaking change + rollback:** `none` — dispatcher prose. Revert the merge to roll back.

