# fix(pre-push): the body is reconciled against the head the push PUBLISHES

## Summary

Head `3f84384fa114a9cafa97e9f13da14fe868e03197` — 4 files changed, 297 insertions(+), 61 deletions(-).

The pre-push gate reconciled the PR body against the diff of the CHECKOUT's `HEAD`, and the org's body linter judged the body's own head claim against that same checkout. A push of a branch other than the checked-out one publishes THAT branch's commit — `git push origin other` publishes `other`'s sha while the checkout still sits on `main` — so both readers judged the body against a tree the push does not publish: a body that described the pushed branch was BLOCKED, and a body that described the checkout was let through. That is the defect opencharly/opencharly#744 filed; it was separable from the hook's argument contract, so it lands in its own PR, and this is it.

The fix resolves the published refs ONCE — the branch AND the commit the push publishes — and names that commit to BOTH readers of the body's head claim. The checked-out tree stays the fallback for a push that publishes no single branch (a tag, a deletion, several branches at once, or a hand-run hook): the tree it always read.

| file | what it carries |
|---|---|
| `scripts/check-pr-body-diff.mjs` | `--head <rev>` (default `HEAD`), and every arm that reads the tree — the diff, the file table, the pasted evidence, the rewritten record's claims, the reader-independent count — reads that ONE head. |
| `hooks/pre-push` | the published refs resolved once from the refs git writes to the hook's stdin; the published commit named to the reconciliation and to the org linter alike; the checked-out tree kept as the fallback. |
| `scripts/check-pr-body-gate.mjs` | the fixture's second branch moved onto a DIFFERENT tree, so the two branches can be told apart; two new FIRED arms that discriminate them; three new static assertions; three new mutations, plus the two the moved invocations needed. |
| `CHANGELOG/2026.300.1647.md` | the merged record's claim that the reconciler compares the body against `origin/main...HEAD` — corrected in the same cutover, because a record that states the old thing is a claim the tree does not support. |

Closes #744
