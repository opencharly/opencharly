# 2026.312.2352 — fix(check): the schema-pattern gate reconciles the files it judges

## Summary

`scripts/design-dpat.sh` now reconciles the file count its readers report with the number of `@@FILE` markers the scanner can actually see — on every run and in `--emit-census` — and fails when they differ. This is the missed control behind the reader defect opencharly/opencharly#948 fixed: a pinned blob with no final newline glued the next file's marker onto its own last line, the scanner never saw that marker, and every line of the next file was judged under the PREVIOUS file's name — a smaller scan quietly reporting success over a file it never attributed. #948's newline guarantee removes the cause; this makes the property a check rather than an assumption, so a future reader that breaks the stream's grammar is caught by the gate itself, not only by the self-test.

Carries the second commit of opencharly/opencharly#948 (its first commit merged as `74aa50e`). The body of #948 was restored to the tree it landed, so the merged record and its CHANGELOG describe exactly what merged; the remainder is here.

Two behaviours make it a control rather than a log line:

- **The reconciliation runs where the claim is made, from ONE implementation.** `reconcile_markers` compares the count the readers incremented with the number of markers the scanner can see, and both callers use it: `run_check` turns a mismatch into a FAIL line, and `--emit-census` refuses to print a census over a stream it cannot attribute (exit 2 rather than a smaller file). So "the gate judges every in-scope file" — the claim A.11 makes and the census depends on — is a check, with the predicate and its sentence in one place.
- **The refusal is proven, and so is the escape it blocks.** The self-test feeds the reconciliation a stream whose marker is glued onto the previous line and asserts the refusal; the case that already existed (a violation planted in the file AFTER a no-trailing-newline blob) asserts attribution, and was shown to fail on the wrong file when the newline guarantee is removed.

| File | What it holds |
|---|---|
| `scripts/design-dpat.sh` | one `reconcile_markers` helper called by `run_check` and by `--emit-census`, its comment stating why the two counts must agree, and one new `--self-test` case that feeds it a glued stream |
| `DESIGN.md` | A.11's "The stream's grammar" now says the property is checked on every run rather than assumed |
