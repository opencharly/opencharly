# 2026.308.0723 — feat(design): let a marketplace carry its settings and its servers (batch 11)

## Summary

Batch 11 of the DESIGN amendments the capability ledger records (tracked in #838). `kind:marketplace`
lost two fields: the per-family `.mcp.json` server wiring and the enabled-plugin list.

- `#Marketplace` gains `settings.enabled_plugin`;
- `#MarketplaceFamily` gains `mcp_server` — a map of name to launch entry;
- `#McpServerRow` types that entry (`command`, `arg`, `env` or `url`).

Two of the design's own naming rules shaped it: `settings` joins D-NAME-1's singular list, and the
entry is named `Row` because D-NAME-4's suffix set has no `Spec`.

| `DESIGN.cue` | `#MarketplaceSettings`, `#McpServerRow`, and the two fields |
| `DESIGN.md` | D-NAME-1's list; the corpus example names an enabled-plugin list and one charly MCP server |
| `design/dulling.tsv` | `kind:marketplace` becomes sharp |
