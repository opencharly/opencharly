# 2026.234.1224 — Drop CHANGELOG placeholder, simplify workflows, add dotgithub submodule

## CI/workflow refactor

- Drop the CHANGELOG placeholder/rename mechanism; the tag-on-merge workflow
  now creates `CHANGELOG/<calver>.md` from the PR body's `## CHANGELOG`
  section at merge time.
- Simplify the `charly/pr-validator` dispatcher (drop the wait-ci job);
  auto-merge fires only when all branch-protection checks are green.
- Simplify `tag-on-merge` to `pull_request: closed` + schedule sweep.
- Add `dotgithub` submodule pinning the org-wide reusable workflows.
