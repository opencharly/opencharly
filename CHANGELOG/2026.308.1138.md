# 2026.308.1138 — feat(design): settle five vendor verbs against what is authored (batch 16)

## Summary

Batch 16 of the DESIGN amendments the capability ledger records (tracked in #838). Five verbs were
dulled because their plugin declares more operations than the design has arms. Measured against what
authored documents actually dispatch, **four of them map onto arms the design already carries, and the
fifth — appium's screen recorder — needed one new arm**:

```console
$ python3 inventory.py
appium  {'status': 4, 'session-create': 3, 'app-start-activity': 3, 'find': 3, 'method': 1}
cdp     {'session': 3, 'list': 3, 'open': 3, 'text': 3, 'status': 1}
mcp     {'call': 6, 'ping': 4, 'list-tools': 3}
spice   {'status': 11, 'screenshot': 10, 'type': 7, 'mouse': 4, 'click': 4, 'key': 4}
wl      {'hypr-layers': 97, 'key': 33, 'screenshot': 33, 'hypr-clients': 21, 'focus': 18, 'type': 12, 'close': 12, 'clipboard': 12, 'exec': 12, 'status': 7}
```

| verb | the arms that carry every authored operation |
|---|---|
| `cdp` | `session`, `tab` (the tab list), `open`, `text`, `status` |
| `spice` | `status`, `screenshot`, `click`, `mouse`, `type`, `key` |
| `appium` | `status`, `session` (create/delete), `activity`, `element`, `record` (the added recorder), `page_source` |
| `mcp` | `call`, `ping`, `tool` (an absent name lists) |
| `wl` | `surface` (`hypr-layers`), `screen` (`hypr-monitors`), `window` (`hypr-clients`), and the twelve generic arms |

The operations nobody dispatches are the plugin's own IPC surface, which **D-PLUG-7** leaves to the
plugin. Five rows become `sharp` against that reading; the four verbs with an operation still outside
the arms (`cua`, `jetkvm`, `vnc`, `dbus`) **stay dulled**.

One arm had to be **added**, not mapped: the inventory's `appium {'method': 1}` is the scalar-map sugar for
`appium: {method: session}` — the **screen recorder**, which is not `session-create`. `appium` gains
`record: {action, artifact}` (`#AppiumCheckRecord`), the example starts a recording, and the row says
which arm carries that `method: session` rather than leaving it to the reader.

| file | what changed |
|---|---|
| `DESIGN.cue` | `#AppiumCheckRecord` and the `record` arm |
| `DESIGN.md` | the protocol-verbs example starts an appium recording |
| `design/dulling.tsv` | five rows become sharp against the arms they name, citing D-VERB-4 |
| `design/dulling-disposition.md` | regenerated from the ledger |
