Both are fixed here, in one commit — and both are the SAME defect issue #775 was filed for, one verb and one clause further in: a control that recognizes a class in only some of its own wordings.

**1. The trigger's verb alternation was missing an inflection.** Every verb of the class carried its own inflections, the past tense included, except the verb that opens the class: the trigger read `touch(es|ing)`, so "the diff touched a submodule" — the retired rule in the past tense — was a wording of the class the key did not recognize.

**2. The scope guard could be DEFEATED by an org-wide clause.** The guard excuses a claim that STATES whose gate it is ("that repo's own", "the umbrella's own", "in a clone of the umbrella"). But a claim that states whose gate it is AND then states the rule org-wide — "the umbrella pin gate applies in every repo whenever the diff touches a submodule" — is false in every repo but one: the two clauses cancel, and the guard excused it because it asked for the scope phrase and never asked whether an org-wide clause stood beside it.

**The fix.** (1) Every verb of the class carries its own inflections, the past tense included. (2) A scope phrase excuses the trigger only when the claim carries NO org-wide marker: the exemption is (SCOPE AND NOT ORG-WIDE). The marker set is REPO-wide claims — "in every repo", "org-wide", "across the org" — and never claims about DIFFS, because "any diff" scopes the diffs the gate applies to, not the repos it applies in, and the umbrella's own true wording uses it. Both sets are ONE canonical constant each, shared by both classes (R2).

**The umbrella's own prose stays GREEN.** Two lines in the umbrella's tracked tree carry a trigger; both carry a scope phrase and neither carries an org-wide marker (§4).

**The coverage.** Two self-test instances are added, one per new wording, and the self-test now runs 35 instances and 26 counter-instances across the same 13 classes (§1).
