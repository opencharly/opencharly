# 2026.301.0542 — fix(gate): a number's ROLE, not its adjacency, says what it counts

Closes #761

## Summary

Head `d94a48fb82f232cf81209e6c91d6a000be311e71` — the commit this PR pushes: **1 file changed, 53 insertions(+)**.

**The umbrella's measured-figures control read a number's ADJACENCY and never its ROLE.** `RE_SHAPE_COUNT` matches a number next to a collection noun and asks whether the clause that states it carries a date. The count family's precision lives in its NOUN list, and that list's own doc records three sibling defects of exactly this class — *"the `0700` directory"* (a file MODE), *"`skill.missing_description`"* (a diagnostic NAME), *"the `skill:` node"* (a field NAME) — each fixed by narrowing the NOUN. What none of them covers is the number's ROLE: nothing asked whether a number is bound to a port, a uid, a gid, a pid or a mode.

So a sentence whose number is a PORT or a UID was read as an undated count of a growing collection, and a tree carrying it was reported as broken. The two live sites are correct prose, and both are in the CORPUS's tree:

| site | the sentence | what the number is |
|---|---|---|
| `DISPATCHER.md:124` and `versa/skills/marimo-mcp/SKILL.md:4` | the marimo MCP server "on port 2718 path /mcp/server" | a PORT, in front of a URL path |
| `coder/skills/uv/SKILL.md:37` | the auto-intermediate machinery "bakes uid=1000 paths into boxes" | a UID, in front of a filesystem path |

The adjacency is coincidental, and the family read it as a count claim. The issue is opencharly/opencharly#761.

**The control** — `scripts/check-readme-measurements.mjs` gains `RE_SHAPE_ROLE`, read from the text IMMEDIATELY BEFORE the number, the same way the cap is: a role word standing ALONE ("port N", "uid=N"), or a COMPOUND identifier whose LAST TOKEN is a role word and which is bound ("USER_UID=N", "listen_port=N").

**What the arm does NOT do, and why that difference matters.** A plain word that merely ENDS in a role word is not a role, and the binding alone does not make it one: "export", "import", "report" and "support" all end in one. An arm that read only the binding would have gone SILENT on a report line that states a count of calls — a hole in the very family this arm strengthens. A word is a role only when it stands ALONE, or when the identifier's own structure says it is a NAME: the role word is one TOKEN of a compound, separated by `_` or `-`. The self-test carries a case on each side, and the case that goes RED under the looser rule is what proves the tightening — a test that cannot fail is invalid (R7).
