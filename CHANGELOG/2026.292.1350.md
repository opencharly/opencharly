# 2026.292.1350 — docs: add verified containerd, crun/krun, k3s and libkrun deployment specs

## Summary

Adds three root-level specification documents for the deployed container stack, measured on the two
live hosts and re-validated by an independent validator. Documentation-only: no code, config or
gitlink changes.

- `CONTAINERD.md` — one containerd shared by nerdctl and k3s; rootful and rootless instances; the
  crun/krun runtime handlers; systemd images; nesting; name resolution; the snapshotter model with
  snapshot/revert at every level (image, layer, store, snapshotter API, microVM); BTRFS and XFS
  layouts (the btrfs-subvolume host and the single-XFS-root host, including reflink
  snapshot/revert); GPU, DRM and NVIDIA container toolkit; reference file map and acceptance checks.
- `K3S.md` — external containerd configuration, verification, image handling, backup and restore
  (logical and full data-dir loss), BTRFS/XFS datadir setup and cluster snapshot/revert, GPU devices.
- `LIBKRUN.md` — libkrun device inventory, virtio-vsock, TSI, virtio-net, the annotation reference,
  a measured launcher and the guest test clients.

Closes #516
