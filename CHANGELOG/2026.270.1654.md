# 2026.270.1654 — docs(agents): formalize agent identity & comment coordination (extends rule 9)

## Summary

Formalize how agents identify themselves and coordinate through GitHub comments, and
extend rule 9 with the mandate. Same-account sessions (this host shares ONE account) are
indistinguishable by comment author, so:

- **Identity is TWO italic lines** — the `Assisted-by` trailer plus a separate `Agent:`
  line naming the WORK (`<slug>`) and the session; the slug is the authority key.
- **Authority is a closed, greppable verb grammar** — a coordination comment's first
  non-blank line is `CLAIM` · `OWNING` · `HANDING OVER` · `TAKING OVER` · `BLOCKS` ·
  `UNBLOCKS` · `STATUS` · `RESOLVED`.
- **Optional by default; MANDATORY on the trigger** — two or more agents on one issue/PR,
  OR a blocking dependency (`BLOCKS`/`UNBLOCKS`).
- **Same-account authority** — the LATEST `OWNING`/`TAKING OVER` for a scope wins; never
  push to another slug's claimed branch without a `HANDING OVER`, a `TAKING OVER` naming
  your `authority:`, or operator sign-off.
- **Takeover + window** — `authority: hand-off | operator | window-expired`, posted BEFORE
  any push; the window runs on `charly/pr-validator` run COMPLETION, never on session activity.
- **Delegation ≠ impersonation** — a sign-off at the operator's explicit direction,
  labelled delegated and carrying the agent's own footer, is valid.
